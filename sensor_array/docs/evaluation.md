# 62 折留一评估：双指数骨架与三路独立 MLP 残差

2026-11-19。评估对象是 [model.md](model.md) 中的两个模型：纯双指数骨架
（<code>double</code>）和双指数骨架 + 三路独立 MLP 残差（<code>mlp_per_gas</code>）。
本分支只保留这两个模型，旧模型代码与结果已删除。数据只使用
<code>data/0.csv</code>–<code>data/61.csv</code> 共 62 条实验，不补测、不补采。

## 1. 结论

- 纯双指数骨架的曲线宏 nRMSE 为 **3.30%**，三路独立 MLP 组合为 **1.48%**。
- 10 s 下游三气体宏中位绝对相对误差：骨架 **4.99%**，三路独立组合 **2.14%**；
  5 s 分别为 **7.42%** 和 **2.96%**。
- 三路独立组合相对骨架：曲线宏 **59/62** 折改善，中位差 **−1.80 百分点**，
  双侧 Wilcoxon p = 1.36e−11；10 s 下游宏 **47/62** 折改善，中位差
  **−2.14 百分点**，p = 3.93e−7；5 s 宏 **45/62**，中位差 **−3.14 百分点**，
  p = 2.50e−6。
- 开发集 50 条与锁定测试 12 条方向一致：曲线宏改善 47/50 与 12/12，
  10 s 下游宏改善 36/50 与 11/12。锁定集只作描述性复核，不参与选型。
- P4 只用开发集 50 条重新拟合区间：原始 Laplace 90% 区间严重欠覆盖，
  全局共形把开发集与锁定集的 10 s 覆盖率拉回名义值附近；分组共形没有带来
  稳定的宽度收益。点估计不变，停止策略与剖面似然本轮没有重做。
- 因此把 <code>artifacts/models/mlp_per_gas.json</code> 作为当前默认模型；
  <code>double.json</code> 保留作骨架对照。

## 2. 协议

- **留一实验（LOGO）**：每次留出 1 条完整曲线，用其余 61 条训练；共 62 折。
  不随机拆时间点，避免同一条曲线的信息泄漏。
- 每折先拟合双指数骨架，再用同一训练集拟合三路独立 MLP；两个模型共享完全相同的
  训练折与留出文件。
- 曲线指标：逐通道
  \(\mathrm{nRMSE}=\mathrm{RMSE}/\mathrm{RMS}_{\text{训练折}}\)，宏平均为三路算术平均。
  训练折 RMS 同时用于模型误差量纲，不参与留出文件的标准化。
- 下游指标：在 5 s、10 s 前缀上用同一套 MAP 估计浓度；残差为数据加权误差 +
  对数正态先验 + 边界软墙。两个模型各自使用训练折 in-sample 残差尺度
  \(\sigma_{\mathrm{eff}}=\sqrt{\sigma_{\mathrm{noise}}^2+\sigma_{\mathrm{model}}^2}\)。
  因此下游差异包含“模型自报尺度”的差异，不能全部归因于骨架或残差结构。
- 三路独立网络在 GPU 上全批训练；评估时用
  <code>OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1</code>
  限制 BLAS/OpenMP 线程，避免小网络把 CPU 占满。
- 主判断用全部 62 折；开发集 50 条与锁定测试 12 条只作描述性复核，不用于选型。
  锁定测试为 <code>{2,7,15,20,23,27,31,38,41,46,55,60}</code>。
- 逐文件配对差定义为候选模型减对照模型；负值表示候选更好。区间为按文件重采样的
  bootstrap 百分位 95% CI（100,000 次重采样），p 值为双侧 Wilcoxon 符号秩检验。

## 6. P4 区间校准

### 6.1 设计

区间在 **log 浓度空间**构造，避免旧实现把浓度误差与标准误混算。对每个折外估计，
记 \(\hat\theta\) 为浓度点估计、\(\mathrm{se}_{\log}=\mathrm{se}/\hat\theta\)，则区间为

$$
\left[\hat\theta\exp(-q\,\mathrm{se}_{\log}),\ \hat\theta\exp(q\,\mathrm{se}_{\log})\right],
$$

相对宽度为 \(\exp(q\,\mathrm{se}_{\log})-1\)。原始 Laplace 90% 区间取
\(q=1.6449\)。

共形校准的分数为

$$
s=\frac{|\log(\hat\theta/\theta_{\mathrm{true}})|}{\mathrm{se}_{\log}}.
$$

**只用 50 条开发集拟合分位数**；开发集内采用留一文件，锁定文件使用全部开发集
分位数。这样 12 条锁定测试既不参与点模型选择，也不参与区间宽度校准，只做
描述性复核。分组方法分三种：

- <code>conformal_all</code>：全局一个分位数；
- <code>conformal_NH3</code>：按 NH3 的 5 个浓度档位分组，组内样本少于 2 时回退全局；
- <code>conformal_block</code>：按连续 8 个文件为一个采集块分组，末组 6 条，同样回退。

这些区间只针对三路独立 MLP 的折外估计；没有为骨架重复校准，也没有重做
停止策略、剖面似然或嵌套协方差。

### 6.2 结果

表 6.1 是 10 s 窗口的 90% 区间：开发集 50 条的覆盖率、中位相对宽度，以及锁定 12 条的覆盖率。

| 方法 | 开发覆盖 H₂ / NH₃ / NO₂ | 开发中位宽度 H₂ / NH₃ / NO₂ | 锁定覆盖 H₂ / NH₃ / NO₂ |
|---|---:|---:|---:|
| 原始 Laplace | 32.0 / 30.0 / 6.0% | 0.6 / 0.7 / 0.9% | 8.3 / 41.7 / 25.0% |
| 全局共形 | 92.0 / 92.0 / 92.0% | 3.5 / 3.4 / 8.7% | 100.0 / 91.7 / 100.0% |
| NH₃ 档位共形 | 90.0 / 90.0 / 90.0% | 3.9 / 5.4 / 9.6% | 100.0 / 91.7 / 100.0% |
| 采集块共形 | 84.0 / 84.0 / 84.0% | 3.5 / 3.0 / 9.2% | 91.7 / 91.7 / 100.0% |

5 s 窗口的趋势相同：原始 Laplace 的开发覆盖为 34.0 / 46.0 / 32.0%，全局共形为
92.0 / 92.0 / 92.0%，中位宽度为 6.5 / 9.5 / 13.7%。但 NH₃ 档位共形在 5 s 锁定集上
NH₃ 气体只有 83.3%，说明分组在小样本上不稳；全局共形在锁定集为 100.0 / 100.0 / 100.0%。

读法：

- 原始 Laplace 的区间过窄，10 s 覆盖率只有 6%–32%，NO₂ 最差；这说明局部曲率
  不能代表模型偏差。
- 全局共形把开发覆盖拉到 92%，锁定集为 91.7%–100%；代价是宽度从不足 1% 放大到
  3%–9%，这是“承认模型偏差”的必要成本。
- NH₃ 档位共形没有更窄：10 s 三气体宽度 3.9 / 5.4 / 9.6%，都大于全局共形；
  12 条锁定里 NH₃ 覆盖 91.7%，5 s 时只有 83.3%。分组只在小样本里重新分配分位数，
  既没有稳定收益，也会在小组上失稳。
- 采集块共形在开发集只有 84%，低于 90% 名义值；不能因为锁定 12 条看起来正常就
  说它更好。
- 结论：**全局共形是当前最稳妥的默认区间**；分组共形只作为诊断，不推荐作为运行级
  保证。区间只覆盖三路独立 MLP 的折外估计，没有为骨架重复校准。

## 7. 解释与诊断

双指数骨架已经把可共享的浓度—时间结构吸收掉，剩余残差里仍有一部分可预测。
用全量拟合模型检查残差相关性时，三路独立 MLP 的预测残差与真实残差相关系数为
**0.866 / 0.722 / 0.883**（H2 / NH3 / NO2），预测残差标准差约为真实残差的
**0.79 / 0.79 / 0.96**。

这说明三路独立网络学到的主要是可外推的系统残差，而不是只记住训练集的实验特异
波动。NH3 的相关最低、幅度也最小，说明它的残差更接近不可约部分；H2 与 NO2
的残差仍有较强的浓度—时间结构，是组合模型收益的主要来源。

但三路独立同时换了容量（骨架 69 参数 vs 组合 14,211 参数）、训练方式
（联合最小二乘 vs 固定 600 轮全批 Adam）和运行设备，因此不能把收益单独归因于
“三路独立”这一项。可以确定的是，当前这套实现明显比骨架稳。

## 9. 限制

- 三路独立网络是单 seed；固定 600 轮、没有早停，轮数没有按折选择，也没有 seed 方差。
- 下游似然使用训练折 in-sample 残差尺度；两个模型的尺度不同，评估协议包含这一混杂。
- 区间校准只用开发集 50 条拟合分位数，锁定 12 条仅作描述；分位数是有限样本构造，
  不是独立盲测。分组样本最少只有 6–7 条，分组覆盖的波动很大。区间只针对三路独立
  MLP，没有为骨架重复校准；停止策略、剖面似然与嵌套协方差没有在本模型上重做。
- 62 条实验、每个浓度组合 1 条，没有重复；留一误差包含实验间漂移。
- 三路独立有 14,211 个参数，骨架只有 69 个；虽然 62 折整体改善，仍有 3 折变差，
  不能排除对训练集分布较敏感。
- 当前模型只用三种气体；不对第四种气体做任何声称。
