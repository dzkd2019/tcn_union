# 传感器阵列正模型：后续优化路线图

> 状态：P0 已完成（2026-11-18）；后续按 P1–P6 推进。
> 适用范围：`sensor_array/` 的正向动态响应模型、可辨识性分析、早期浓度估计与合成数据实验。
> 硬约束：现有 62 条实验不可扩充（传感器已损坏）；不提出、不依赖补测/补采/重新采集；不重复使用逆问题的 12 条锁定测试做调参。

---

## 1. 这份路线图要解决什么

当前主线已经完成：

- 一阶惯性 + 纯延迟的灰盒骨架；
- 5 条 B 样条时间基 × 10 项对数浓度二次特征的低秩残差；
- 62 折 LOGO 宏 nRMSE 3.02%（灰盒 3.47%，TCN 3.60%，直接岭回归 2.59%）；
- 可辨识性、MAP + Laplace + CV+、自适应停止、传感器降级、误差预算；
- 合成数据 + 循环一致性的逆模型实验（B）。

但现在有三个没有回答清楚的问题：

1. **3% 的曲线误差里，多少是“骨架形状不够”，多少是“实验之间的差异”，多少是“NH3 与采集顺序混淆”？**
2. **换更复杂的模型，能不能真的降低误差，还是只是把 62 条曲线背得更像？**
3. **早期浓度估计的误差，能不能通过“偏差感知”的估计器和更诚实的验证协议来降低，而不是靠调网络？**

路线图的目标不是“再堆一个更大的模型”，而是：

> 先把误差拆开，再决定加什么结构；每加一个结构，都必须用留一档位/留一文件块证明它不是过拟合。

## 3. 三条主线

### 主线 A：把“模型偏差”拆开

不是笼统地说“模型有偏差”，而是分成四类并分别量化：

1. **骨架近似误差**：一阶指数表达不了的真实形状；
2. **实验特异性**：每次实验的基线、增益、缓慢漂移、温度/历史差异；
3. **设计混淆**：NH3 浓度与采集顺序绑定，无法分离；
4. **估计器假设**：噪声独立同分布、模型误差用一个标量 `sigma_model` 概括。

对应工作包：P1（诊断）、P2（分层模型）、P3（结构化残差）。

### 主线 B：让估计器“知道自己可能错”

当前 MAP 用 `sigma_eff = sqrt(noise^2 + sigma_model^2)`，把模型误差当成独立同分布噪声；这会把区间做得过窄或过宽。

对应工作包：P4（偏差感知估计 + 分组校准 + 决策停止）。

### 主线 C：把 B 做成公平实验

当前 B 的 1:1 混合臂真实曝光减半、预训练预算不对称、固定 150 epoch 未收敛；这些都会让结论偏向“合成没用”。

对应工作包：P5（等曝光、等预算、多 seed、功效分析）。B 是次要主线，不阻塞 A。

### P1：残差诊断与更严格的验证（1–2 周）

**目标**：回答“3% 误差从哪来”，并建立后续模型必须通过的验证协议。

**做法**：

1. **残差分解**
   - 对 62 条实验计算混合模型残差 `r_j(t,c)`；
   - 做 PCA/低秩分解，看前几个时间模式；
   - 计算残差与以下变量的相关性：文件序号、NH3 档位、H2/NO2 浓度、初始基线 `R_j(0)`、60 s 末斜率；
   - 画残差热图（时间 × 实验序号）。
2. **验证协议**
   - 现有 62 折 LOGO；
   - 新增 **留一浓度水平**（leave-one-level-out）：固定某个 H2/NH3/NO2 档位，整档留出；
   - 新增 **留一文件块**（leave-one-block-out）：按采集顺序留出连续 8–10 条；
   - 新增 **传感器降级**：去掉一路输入，看三路浓度误差（已有 10 s 版本，扩展到 2/5/20/60 s）；
   - 所有协议使用同一套 `curve_metrics` 与浓度指标。
3. **下游指标选模型**
   - 不再只用曲线 nRMSE 选模型；同时报告 5/10/20 s 的浓度中位误差、p90、覆盖率；
   - 曲线更好但浓度更差的模型，不选。

**产出**：

- `analysis/residuals.py`（新）：残差分解、相关表、诊断图；
- `artifacts/analysis/residual_diagnostics.csv`；
- `docs/chapter_results.md` 增补“残差诊断”一节；
- 验证协议函数进入 `core/metrics.py`，供后续模型复用。

**验收**：

- 能明确回答：残差与文件序号/NH3 档位的相关是否显著；
- 留一档位/文件块的数字进入结果表；
- 若残差与文件序号高度相关，后续模型必须显式处理漂移，否则不继续加复杂度。

**止损**：如果残差与文件序号/NH3 档位相关很弱，说明主要问题不是漂移，P2 的优先级下调。

### P2：分层/混合效应正模型（2–3 周）

**目标**：把“实验之间的差异”显式建模，而不是让低秩残差去吸收。

**模型草案**：

对实验 \(i\)、传感器 \(j\)：

\[
y_{ij}(t)
=
s_j A_j(c_i)(1+\eta_{ij})
\left[1-e^{-(t-d_j)_+/\tau_j(c_i)}\right]
+
\beta_{ij} g(t)
+
\varepsilon_{ij}(t)
\]

其中：

- \(\eta_{ij}\sim N(0,\sigma_\eta^2)\)：实验级增益随机效应；
- \(\beta_{ij}\sim N(0,\sigma_\beta^2)\)：实验级漂移随机效应；
- \(g(t)\)：缓慢漂移基（如 \(t/60\) 或 2–3 条 B 样条）；
- \(\varepsilon\)：测量噪声。

**做法**：

1. 先做“固定效应 + 实验级随机截距/斜率”的线性混合模型，用 penalized least squares 或 EM 拟合；
2. 与当前混合模型对比：
   - 只加随机增益；
   - 只加随机漂移；
   - 两者都加；
3. 用 P1 的 LOGO/留一档位/留一文件块评估；
4. 报告方差成分 \(\sigma_\eta^2,\sigma_\beta^2\)，回答“实验间差异占多少”。

**产出**：

- `core/hierarchical.py`；
- `artifacts/models/hierarchical.json`；
- 方差成分表、对比图（fig17）。

**验收**：

- 相比当前 3.02%，LOGO 宏 nRMSE 至少下降 0.2 个百分点，或留一文件块明显更稳；
- 方差成分可解释（例如实验间增益差异 5–10%）；
- 若没有稳定收益，停止该方向，不把随机效应硬塞进论文。

**风险**：

- 62 条、每条一个随机效应，可能估计不稳；
- 随机效应会吸收 NH3/time 混淆，不能把它解释成“NH3 效应”；
- 若随机效应与浓度特征共线，固定效应会漂移。

### P3：结构化残差（1–2 周，可与 P2 并行）

**目标**：把当前 5 条自由 B 样条换成“有物理含义的修正”，降低残差吸收漂移的风险。

**做法**：

1. 把残差拆成三部分：
   - 早期瞬态修正（0–10 s，2 条基）；
   - 中期形状修正（10–30 s，1–2 条基）；
   - 缓慢漂移（30–60 s，单调基，1 条）。
2. 对漂移基加单调/平滑约束；
3. 比较：
   - 自由 B 样条（当前 K=5）；
   - 结构化基（同样 5 条）；
   - 结构化基 + 分层随机漂移（P2）。
4. 诊断：结构化后残差与文件序号的相关是否下降。

**产出**：

- `core/hybrid.py` 增加 `basis="structured"` 选项（不新建模块）；
- fig17/fig18：残差基对比、残差-文件序号相关。

**验收**：

- 精度不显著变差（≤0.1 pp）；
- 残差与文件序号的相关下降，或至少不上升；
- A/τ 的可解释性保持。

**止损**：若结构化后精度明显变差，保留自由 B 样条，但在论文中说明“残差可能吸收漂移”。

---

### P4：偏差感知的早期估计（2–3 周）

**目标**：让区间和停止策略反映“模型也可能错”，而不是只反映噪声。

**做法**：

1. **模型偏差项**
   - 用 P1/P2 的残差协方差估计 \(\Sigma_\delta\)；
   - 估计器从“独立同分布噪声”改成广义最小二乘/带相关误差的 MAP；
   - 比较 `sigma_eff` 标量版与协方差版。
2. **分组校准**
   - CV+ 按 NH3 档位/文件块分组报告覆盖率；
   - 若分组覆盖率偏离名义值，改用 group-wise conformal 或经验膨胀；
   - 不再只报告总体 91.9%。
3. **决策停止**
   - 当前停止目标是“区间宽度 ≤ 10%”；
   - 改成“给定下游决策的损失”：例如浓度是否超过报警阈值，等待下一窗的期望收益 vs 误判损失；
   - 报告停止时间分布与误判率。
4. **可辨识性剖面**
   - 用剖面似然/boostrap 替代单纯 CRLB，至少在代表实验上；
   - 说明模型偏差使 CRLB 过于乐观。

**产出**：

- `analysis/estimation.py` 扩展（协方差、分组校准、决策停止）；
- `artifacts/analysis/coverage_by_group.csv`、`stopping_decision.csv`；
- fig19–fig21。

**验收**：

- 10 s 中位误差：H2 ≤4.0%、NH3 ≤2.5%、NO2 ≤6.0%；
- 分组覆盖率 85–92%（名义 90%）；
- 10% 停止目标 ≥20/62，且误判率可接受；
- 若协方差版没有改善，保留标量版并说明原因。

### P5：公平的 B 实验（1–2 周，可选）

**目标**：把“合成数据有没有用”做成公平比较，而不是预算不对称的比较。

**做法**：

1. 等曝光：8 真实 + 8 合成（batch 16），或混合臂步数加倍；
2. 等预算：预训练 100 epoch + 微调 150 epoch，与真实臂 150 epoch 对齐；
3. 5 个 seed × 5 折，报告均值、标准差、配对差；
4. 用 P1 的下游指标（5/10 s 浓度误差），不只 MAPE；
5. 若仍无显著收益，明确写“在现有 62 条上，合成数据不是有效的信息来源”。

**产出**：

- `artifacts/augmentation/fair_comparison.csv`；
- `docs/chapter_results.md` §8 更新；
- 一张 fig22：等曝光/等预算下的臂对比。

**验收**：

- 每个臂的真实曝光和总步数可核对；
- 结论与置信区间一致；
- 不显著就写不显著，不挑 seed。

## 6. 风险与止损

| 风险 | 表现 | 止损 |
|---|---|---|
| 过拟合 62 条 | LOGO 好、留一档位/文件块差 | 以留一档位/文件块为准，砍掉复杂结构 |
| 随机效应吸收 NH3 混淆 | 方差成分很大、固定效应漂移 | 不把随机效应当成浓度效应；论文写明 |
| 残差吸收漂移 | 残差与文件序号高相关 | 结构化残差/显式漂移项；否则不解释 A/τ |
| 协方差估计不稳 | 62 条估不出 299×299 协方差 | 用低秩/对角近似；否则退回标量 |
| 分组覆盖率差 | 某些 NH3 档位覆盖低 | 报告分组覆盖率，不调参掩盖 |
| B 仍无收益 | 等曝光后差异仍小 | 写负结果，停止 B |
| 12 条锁定集被误用 | 调参用了测试 | 明确禁止；只用 62 折与留一档位/块 |

## 9. 成功标准（本章可写的故事）

1. **模型**：分层/结构化模型在留一档位/文件块上不差于当前 3.02%，且残差与文件序号的相关下降；
2. **可辨识性**：明确“噪声不是瓶颈、盲基线不可行、NH3 与时间是混淆”的三条结论；
3. **估计器**：10 s 中位误差与分组覆盖率同时达标，停止策略有决策解释；
4. **B**：公平实验后，要么给出稳定收益，要么给出可信的负结果；
5. **复现**：所有数字能由 `artifacts/` + 命令重跑，文档与图号一致。

## 10. 不做什么

- 不补测、不补采、不重新采集；不把“再测一批”写进任何计划；
- 不把 12 条逆问题锁定集用于本章调参或模型选择；
