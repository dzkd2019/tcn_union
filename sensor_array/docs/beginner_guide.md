## 0. 先读这一页

### 0.1 为什么需要两种说法

同一个概念，严谨说法和通俗说法承担不同任务：

- **严谨说法**用于写论文、读代码、判断一个结论能不能成立。它必须说清定义、公式、前提和边界。
- **通俗说法**用于建立直觉。它不追求字字精确，而是让你先知道“这个东西大概在干什么”。
- **类比边界**用于防止直觉越界。所有类比都会在某处失真；把失真的地方标出来，比换一个更漂亮的类比更重要。

例如“时间常数”可以比作“倒水时杯子快满的程度”，但杯子不会像传感器那样出现慢漂移、负响应或多时间尺度。类比帮助你进门，边界提醒你不要把门当成整座房子。

### 0.2 学习路线

| 遍数 | 读什么 | 目标 |
|---|---|---|
| 第一遍 | 第 1–3 章 | 知道问题、数据、验证和指标 |
| 第二遍 | 第 4–5 章 | 理解正模型、逆问题和不确定度 |
| 第三遍 | 第 6–8 章 | 理解决策、合成数据、统计比较 |
| 第四遍 | 第 9–12 章 | 把数字放回项目，检查误区，做自测 |

公式可以第一遍跳过；每张卡片的“边界”不要跳过。边界往往就是论文里最容易被审稿人追问的那句话。

### 0.3 符号与约定

- $t$：时间，单位秒。
- $R_j(t)$：第 $j$ 路传感器的原始读数；本项目有三路。
- $y_j(t)$：相对响应，后面定义。
- $c = (c_H2, c_NH3, c_NO2)$：三种气体的浓度向量。
- $\theta = \log c$：对数浓度；估计器通常在这个坐标里工作，因为浓度跨数量级。
- $f(t; c)$：正模型，即“给定浓度，预测曲线”。
- $\hat c$：从曲线反推出来的浓度估计。

数据文件没有注明浓度的物理单位。本文只写“原始单位”或具体数值，**不臆造单位**。另外，CSV 里的 $H2 / NH3 / NO2$ 三列是**三块传感器的响应**，不是浓度列；浓度在 $conc1 / conc2 / conc3$，依次对应 H2 / NH3 / NO2。

## 1. 我们在测什么

### 1.1 传感器阵列

**严谨说法.** 传感器阵列是由多个对多种气体都有响应的传感单元组成的测量系统。每个单元输出一个随时间变化的信号；不同单元对同一气体的灵敏度不同，同一单元对不同气体也可能都有响应。阵列的价值不是“一个传感器测一种气体”，而是用多通道的交叉敏感 pattern 做联合推断。

**通俗说法.** 三块“嗅觉细胞”同时闻同一袋气体，各自报一个随时间变化的读数。没有哪一块只对一种气体负责；要三块一起看，才能猜出配方。

**边界.** 阵列不等于“把三块传感器变成三台选择性仪器”。交叉敏感仍然存在，只是从“单通道无法分离”变成了“多通道可以联合建模”；如果通道之间高度共线，联合建模也未必能分离。

### 1.2 响应曲线

**严谨说法.** 在一次浓度近似恒定的实验里，第 $j$ 路读数随时间变化的轨迹 $R_j(t)$。它通常包含初始基线、瞬态上升/下降、接近稳态的部分，以及缓慢漂移或采集伪影。

**通俗说法.** 把传感器放进气体后，读数从起点慢慢爬到新平台的那条线。

**边界.** 曲线不是气体的“指纹”。不同浓度组合可能产生很相似的曲线；基线、老化、管路延迟、采集跳变都会改变曲线。看到一条曲线，不能直接说“这就是某种气体”。

### 1.3 正问题

**严谨说法.** 给定浓度向量 $c$ 和正模型 $f$，预测响应曲线 $y(t) = f(t; c) + ε$，其中 $ε$ 是噪声和模型未解释部分。评价通常看曲线层面的误差，例如 nRMSE。

**通俗说法.** 知道气体配方，推算传感器会画出什么曲线。

**边界.** 正问题准，不代表逆问题唯一。正模型可以很准确地拟合曲线，但反推浓度仍可能因为多条曲线相交、噪声或设计混淆而不稳定。这是两个不同的问题。

### 1.4 逆问题

**严谨说法.** 给定观测曲线 $y$，估计浓度 $c$。这是一个非线性反演问题；在有限时间窗、噪声和模型偏差下，可能是病态的（多个 $c$ 都合理，或解对噪声很敏感）。

**通俗说法.** 只看曲线，猜气体配方。

**边界.** 逆问题不是“把正问题公式倒过来除一下”。真实数据里，模型偏差往往比噪声大；仅靠最小二乘反推，可能得到一个拟合很好但浓度错的答案。

### 1.5 浓度档位与实验设计

**严谨说法.** 实验设计中，每个因素取若干离散水平，称为档位；设计矩阵的每一行是一次实验，每一列是一个因素。档位之间的组合决定了你能把哪些效应分开、哪些只能靠假设。

**通俗说法.** 一张配方表：H2 有四档、NH3 有五档、NO2 有五档；62 次实验只覆盖了其中一部分组合，不是完整的笛卡尔积。

**在本项目里.** H2 ∈ {8000, 16000, 24000, 32000}，NH3 ∈ {10, 20, 30, 40, 50}，NO2 ∈ {2, 4, 6, 8, 10}，都是原始单位。文件 0–6 的 NH3=10，7–20 是 20，21–34 是 30，35–48 是 40，49–61 是 50。H2=32000 只有 4 条，而且都在 NO2=2。

**边界.** 档位不是连续均匀采样；边角组合很少。H2 最高档与 NO2 的交互几乎没有覆盖，所以“模型在 H2=32000 上表现如何”不能代表整个高浓度平面。

### 1.6 基线

**严谨说法.** 实验开始或通气前的传感器读数 $R_j(0)$。它受温度、湿度、老化、前序气体、电源历史等影响，不是一个固定的零点。

**通俗说法.** 每次实验前传感器的“零点”。

**边界.** 零点会漂。直接拿原始读数建模，模型可能先学会“这是第几次实验”，而不是学浓度。本项目 NH3 的初始基线从约 786 漂到 7437，差了 9.5 倍；这就是必须处理基线的原因。

### 1.7 相对响应

**严谨说法.** 定义

\[
y_j(t)=\frac{R_j(t)-R_j(0)}{R_j(0)}.
\]

它是无量纲的，满足 $y_j(0)=0$，可以消去通道之间的乘性基线差异。代价是：如果 $R_j(0)$ 很小，除法会放大噪声；它只消掉乘性差异，不消掉加性漂移。

**通俗说法.** 把每条曲线除以自己的起点，只看“相对自己变化了百分之几”。

**边界.** 相对响应不是“真实浓度变化百分比”。H2 的相对幅度中位数只有约 1.1%，所以同样大小的绝对波动，在 H2 上会被放大得更厉害；这也是 H2 的曲线误差通常最难压的原因之一。

### 1.8 混淆

**严谨说法.** 两个或多个因素在数据中高度相关，导致无法在统计上分离各自的效应。混淆是设计问题，不是换一个更复杂的模型就能自动修好。

**通俗说法.** NH3 浓度和实验顺序几乎绑在一起：前面做低 NH3，后面做高 NH3。模型分不清“曲线变化是因为 NH3 变了”还是“传感器老了”。

**在本项目里.** NH3 档位与文件序号的 Spearman 相关约 0.976。H2=32000 只出现在 NO2=2，这也是一种结构性混淆。

**边界.** 相关 0.976 不是 1；如果有额外干预或很强的物理假设，理论上可以部分分离。但现有 62 条数据没有这种干预，所以不能把“与 file 序号相关”直接解释成“漂移是主因”。

## 2. 怎样不骗自己：验证协议

### 2.1 数据泄漏

**严谨说法.** 测试集的信息以任何形式进入训练、调参或预处理，使折外误差变得乐观。泄漏不只发生在标签上；特征标准化、基函数选择、超参数选择、异常值剔除，只要用了全量数据，都可能泄漏。

**通俗说法.** 考试前偷偷看了答案。考场上做得很顺，不代表真的会。

**边界.** “随机拆时间点”是时间序列里最常见的泄漏：相邻时间点几乎一样，测试点很容易被训练点“猜中”。本项目必须整条实验留出，不能随机拆 299 个时间点。

### 2.2 交叉验证

**严谨说法.** 把数据分成若干折，轮流用一部分训练、另一部分验证，重复多次，用验证误差估计泛化误差。折的划分必须尊重数据的分组/时间结构。

**通俗说法.** 轮流锁住一部分数据当“模拟考”，剩下的用来学习；多考几次，取平均。

**边界.** 如果样本之间不独立，普通随机交叉验证会高估性能。比如同一条曲线的相邻点、同一次实验的多个时间窗、同一个 seed 的多个折，都不能当独立样本。

### 2.3 LOGO

**严谨说法.** Leave-One-Experiment-Out：每次留出一条**完整实验**做测试，用其余 61 条训练，重复 62 次。这样测试实验完全没有参与训练，能较诚实地估计“遇到一条新实验”时的误差。

**通俗说法.** 每次拿一条实验当“没见过的新实验”，其余 61 条用来学习；62 条轮流当一次新实验。

**边界.** LOGO 只模拟“新实验”，不模拟“新浓度档位”。如果测试的是外推到没见过的档位，要另做留一档位；LOGO 数字好看，不代表档位外推也好。

### 2.4 留一档位与留一区块

**严谨说法.** 留一档位（leave-one-level-out）：把某个因素的整个浓度水平全部留出，例如所有 H2=32000 的实验都不参与训练，用来评估“外推到未见档位”。留一区块（leave-one-block-out）：按采集顺序留出连续的一段实验（本项目每块 8 条，最后一块 6 条），用来评估“换一段时间采集”的泛化。

**通俗说法.** 留一档位是“把一整档浓度的题全部拿走，看你还会不会”；留一区块是“把一整段时间的题全部拿走”。

**边界.** 档位折数少（H2 4 折、NH3 5 折、NO2 5 折），折间方差很大；区块又与 NH3 档位高度共线，所以“留一区块不掉”不能单独证明“没有漂移”。它只能说明：按这种切法，模型没有明显变差。

### 2.5 锁定测试

**严谨说法.** 事先固定、只在最终报告时使用的测试集；不参与模型选择、超参数选择、特征选择。它的作用是防止“用测试集调模型”带来的乐观偏差。

**通俗说法.** 锁在抽屉里的最终考卷。平时不能用它练手，最后才拿出来。

**在本项目里.** 12 条锁定测试的文件编号是 {2, 7, 15, 20, 23, 27, 31, 38, 41, 46, 55, 60}。所有建模与选择都在其余 50 条开发集上做；锁定测试只做描述性统计，不用来挑方法。

**边界.** 锁定测试只有 12 条，统计不确定性很大；它不是“万能裁判”。而且一旦反复拿它做比较、再改模型，它就不再锁定。

### 2.6 随机种子与折

**严谨说法.** 随机种子控制参数初始化、数据打乱、采样等随机过程；折是数据划分。重复“seed × fold”可以估计结果对随机性的敏感度。

**通俗说法.** 换几次随机起点、换几次分班，看看成绩是不是靠运气。

**边界.** 不能挑一个最好看的 seed 报告；也不能把同一批实验的 25 个 (seed, fold) 当成 25 个独立样本。它们共享实验和折，p 值只能作描述。

## 3. 怎样衡量好坏：指标

### 3.1 绝对误差与相对误差

**严谨说法.** 绝对误差 $e = |\hat c - c|$，与浓度同量纲；相对误差 $e_r = |\hat c / c - 1|$，无量纲。相对误差在 $c$ 接近 0 时不稳定，绝对误差则受量纲和量级影响。

**通俗说法.** 绝对误差是“差了多少”；相对误差是“差的比例”。

**边界.** 跨气体直接平均绝对误差，等于让量程大的气体主导结果；跨样本平均相对误差，又会让小浓度样本主导。所以报告时要写清楚分母和聚合方式。

### 3.2 MAPE

**严谨说法.** Mean Absolute Percentage Error：

\[
\mathrm{MAPE}=\frac{1}{N}\sum_{i=1}^{N}\left|\frac{\hat c_i}{c_i}-1\right|.
\]

**通俗说法.** 平均而言，猜错百分之几。

**边界.** MAPE 对小浓度样本非常敏感，损失也不对称（高估和低估同样的绝对量，百分比不同）。宏平均 MAPE 还会被少数大误差实验拉高；它不等于“典型实验的误差”。

### 3.3 NMAE

**严谨说法.** Normalized Mean Absolute Error。对本项目每个气体：

\[
\mathrm{NMAE}=\frac{1}{N}\sum_{i=1}^{N}\frac{|\hat c_i-c_i|}{\max(c_{\text{train}})-\min(c_{\text{train}})}.
\]

分母是该气体在训练折上的浓度量程。$NMAE$ 不是相对误差；它回答的是“绝对误差占该气体量程的百分之几”。

**通俗说法.** 把误差换算成“占这门课满分多少”。量程越大，同样的绝对误差看起来越小。

**边界.** 量程依赖训练集；不同气体、不同折的 NMAE 不能直接混为一谈。它也不是 MAPE：一个除以真实值，一个除以量程。

### 3.4 nRMSE

**严谨说法.** Normalized Root Mean Square Error，曲线层面：

\[
\mathrm{nRMSE}=\frac{\sqrt{\frac{1}{T}\sum_t(\hat y_t-y_t)^2}}{\sqrt{\frac{1}{T}\sum_t y_t^2}}.
\]

分母是参考相对响应的 RMS，通常取训练折的参考幅度。它无量纲，适合比较不同通道的曲线形状误差。

**通俗说法.** 曲线整体偏了多少，用曲线自己的幅度做尺子。

**边界.** 小幅度通道会被放大：H2 的相对幅度中位数只有约 1.1%，同样大小的绝对波动在 H2 上会被放大得更厉害。nRMSE 也不是浓度误差；曲线准不等于反推浓度准。

### 3.5 中位数与 p90

**严谨说法.** 中位数是 50% 分位数；p90 是 90% 分位数，表示有 90% 的样本不超过它。两者都是分位数，但对尾部的敏感度不同。

**通俗说法.** 中位数是“典型情况”；p90 是“最差的那一成大概有多差”。

**边界.** 62 条样本的 p90 大约只由最差的 6 条决定，数值不稳定；它不能代替完整分布，也不能说明误差为什么大。中位数不反映尾部，p90 不反映典型值。

### 3.6 宏平均

**严谨说法.** 先对每个气体分别算指标，再等权平均：

\[
m_{\text{macro}}=\frac{1}{3}(m_{H2}+m_{NH3}+m_{NO2}).
\]

**通俗说法.** 三门课各算各的，再取平均分。

**边界.** 等权不等于等重要性。某个气体（例如 H2）明显退化，可能被另外两个气体的改善在宏平均里掩盖；所以宏平均必须和逐气体指标一起报。

### 3.7 标准差、标准误与置信区间

这一节回答三个看起来很像、其实完全不同的问题：

1. **单次实验的误差一般有多大？** —— 看标准差（sd），本项目第一阶段用 $3\sigma$。
2. **如果重复做很多次实验，估计量本身会跳多少？** —— 看标准误（se）。
3. **给一个估计值配一个区间，这个区间能不能罩住真值？** —— 看置信区间（CI）与覆盖率。

把这三个问题混在一起，就会得到“se 就是 sd”“3σ 就是置信区间”“覆盖率高就准”之类的错误结论。

#### 3.7.1 标准差：个体之间的差异

**严谨说法.** 设一次实验的某个量是随机变量 $Y$，均值 $\mu=\mathbb E[Y]$，方差 $\sigma^2=\mathrm{Var}(Y)$，标准差 $\sigma=\sqrt{\sigma^2}$。真实 $\sigma$ 未知，用样本标准差估计：

\[
s=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(y_i-\bar y)^2},
\qquad
\bar y=\frac{1}{n}\sum_{i=1}^{n}y_i.
\]

$s$ 回答的是：**这些个体彼此差多少**。它和均值准不准是两件事。比如五次测量是 $10.1,9.9,10.0,9.8,10.2$，均值接近 10，$s$ 很小；如果五次是 $8,9,10,11,12$，均值还是 10，但 $s$ 大得多。

**在本项目里.** 第一阶段的 $3\sigma$ 不是置信区间，而是：

\[
3\sigma=3\cdot\mathrm{sd}\left(r_{1},\dots,r_{n}\right),
\qquad
r_{i}=100\cdot\frac{\hat y_{i}-y_{i}}{\max(|y_{i}|,10^{-9})}.
\]

它衡量的是**相对误差分布的尾部宽度**：$r_i$ 是第 $i$ 个实验（某气体或宏平均）的相对误差，先算这些误差的样本标准差，再乘 3；逐气体时把 $r_i$ 换成该气体的相对误差即可。第一阶段测试集的宏平均 $3\sigma=7.11\%$，意思是“相对误差的 3 倍样本标准差约 7.11 个百分点”，不是“真值有 95% 概率落在 $\pm 7.11\%$ 内”，也不是“标准误是 7.11%”。

**怎么读.** 若误差近似正态、且没有系统偏差，$\pm 3s$ 大约覆盖 99.7% 的个体；但本项目误差有偏、样本只有 12 个测试点，所以不能把 $3\sigma$ 当成严格概率保证。它更适合作为“尾部有多宽”的工程指标：越小，说明最坏的那些实验相对误差越可控。

**边界.** $s$ 对少数极端点很敏感；$n$ 小的时候很不稳定。12 个测试点算出的 $3\sigma$ 会随一两个难例大幅变化，所以第一阶段同时报告 OOF、逐气体结果和测试集只读一次的历史，不把单一 $3\sigma$ 当成普适精度。

#### 3.7.2 标准误：估计量本身的抖动

**严谨说法.** 设 $\hat\theta$ 是某个参数的估计量（例如均值、浓度、增益）。标准误是

\[
\mathrm{se}(\hat\theta)=\sqrt{\mathrm{Var}(\hat\theta)},
\]

即“如果我把整个实验重复很多次，$\hat\theta$ 会在真值附近跳多大”。对 $n$ 个独立同分布样本的均值，

\[
\mathrm{se}(\bar y)=\frac{\sigma}{\sqrt n},
\qquad
\widehat{\mathrm{se}}(\bar y)=\frac{s}{\sqrt n}.
\]

对更复杂的估计量（例如 MAP 浓度、非线性最小二乘参数），没有简单公式，常用两种近似：

- **Laplace/数值 Hessian**：在最优解附近把负对数后验近似成二次型，协方差为 $\mathbf H^{-1}$，对角线开根号得到每个参数的局部标准差；
- **Bootstrap**：有放回重采样，重复估计，直接算 $\hat\theta_b$ 的样本标准差：

\[
\widehat{\mathrm{se}}_{\mathrm{boot}}
=\sqrt{\frac{1}{B-1}\sum_{b=1}^{B}\left(\hat\theta_b-\bar{\hat\theta}\right)^2}.
\]

**在本项目里.** 第二阶段的每个实验、每个时间窗都会用 Laplace 近似给出一个 $\mathrm{se}(\hat{\mathbf c})$，它衡量“在这个实验的噪声和局部曲率下，浓度估计有多不稳”。注意：这个 se 只反映**局部噪声/曲率**，不包含模型偏差；模型错了，se 可能很小，但估计仍然偏得很远。

**边界.** $\mathrm{se}=s/\sqrt n$ 只对“独立同分布样本的均值”成立。本项目的 62 条实验不是独立同分布：它们有采集顺序、NH₃ 档位分块、基线漂移；五折之间还共享训练数据。把 62 个折的指标直接算 $s/\sqrt{62}$，会把不确定性严重低估。因此项目里更多报告**逐折中位数、p90、配对差**，而不是假装 62 个折是 62 个独立重复。

#### 3.7.3 置信区间：带覆盖性质的随机区间

**严谨说法.** 频率派视角下，参数 $\theta$ 是固定的未知常数，区间 $[\ell,u]$ 是随数据变化的随机区间。若对所有 $\theta$ 都有

\[
P_\theta\left(\theta\in[\ell(Y),u(Y)]\right)\ge 1-\alpha,
\]

则称它是置信水平 $1-\alpha$ 的置信区间。对正态均值的经典构造是

\[
\bar y\pm z_{1-\alpha/2}\frac{s}{\sqrt n}
\quad\text{（大样本）},
\qquad
\bar y\pm t_{1-\alpha/2,n-1}\frac{s}{\sqrt n}
\quad\text{（小样本）}.
\]

更一般的构造包括 bootstrap 百分位区间、$t$ 区间、以及本项目的 CV+ 区间。

**怎么读.** “95% 置信区间”不是“参数有 95% 的概率落在当前这个区间里”。当前区间已经算出来了，参数要么在里面，要么不在；95% 说的是**构造区间的程序**：如果我把整个实验重复很多次，每次都重新算一个区间，大约 95% 的区间会罩住固定的真值。对单次实验，我们不知道它是不是那 95% 之一。

**在本项目里.** 第二阶段有两种区间：

- **Laplace 区间**：$\hat\theta\pm z_{1-\alpha/2}\widehat{\mathrm{se}}$，其中 $\widehat{\mathrm{se}}$ 来自局部 Hessian；它假设后验在最优解附近近似二次、且模型没有大偏差。
- **CV+ 区间**：用其他折的折外分数 $|\hat\theta-\theta|/\mathrm{se}$ 的经验分位数 $q$，构造 $\hat\theta\pm q\cdot\mathrm{se}$。它不要求正态，但要求实验之间近似可交换。

**关键教训.** 区间是否有效，不取决于它“看起来宽不宽”，而取决于**覆盖率**。本项目原始 Laplace 区间的 90% 覆盖率只有 16.1/59.7/32.3%（H₂/NH₃/NO₂），剖面似然只有 21.0/38.7/29.0%——不是区间公式写错了，而是估计本身有模型偏差，区间围绕一个偏了的中心，再窄也罩不住真值。CV+ 把总体 90% 覆盖率拉回 91.9%，但这是折外校准的结果，不代表每个实验都可靠。

#### 3.7.4 三者的关系

| 概念 | 回答的问题 | 典型公式 | 本项目中的对应 |
|---|---|---|---|
| 标准差 $\sigma$ / $s$ | 个体之间差多少 | $s=\sqrt{\frac{1}{n-1}\sum(y_i-\bar y)^2}$ | 第一阶段 $3\sigma$；逐折指标的离散度 |
| 标准误 $\mathrm{se}$ | 估计量重复实验时跳多少 | $s/\sqrt n$；Laplace $\sqrt{\mathrm{diag}(\mathbf H^{-1})}$；bootstrap | 每个实验的 Laplace se；折间波动 |
| 置信区间 CI | 区间程序能否罩住真值 | $\hat\theta\pm q\cdot\widehat{\mathrm{se}}$ | Laplace 区间、CV+ 区间 |
| 覆盖率 | 区间实际罩住真值的比例 | $\hat p=\frac1N\sum\mathbf 1\{y_i\in[\ell_i,u_i]\}$ | CV+ 91.9%（90% 名义） |

一句话：**sd 描述“数据散”，se 描述“估计抖”，CI 描述“区间罩不罩得住”；三者不能互相替代。**

#### 3.7.5 常见误读

- **“se 就是 sd 除以 $\sqrt n$。”** 只对独立同分布样本的均值成立；本项目的折之间不独立，不能这么算。
- **“95% CI 表示参数有 95% 概率落在里面。”** 频率派下参数固定，概率属于区间程序，不属于当前这个区间。
- **“$3\sigma$ 就是 $3\times\mathrm{se}$。”** 不是。第一阶段的 $3\sigma$ 是 $3\times$ 相对误差的样本标准差，衡量个体误差的尾部，不是均值估计的标准误。
- **“CI 越宽越可信。”** 宽度和覆盖率是一对权衡；把区间拉到无穷宽，覆盖率 100%，但没有任何决策价值。
- **“62 条就是 62 个独立重复。”** 不是；有采集顺序、档位分块、共享训练折，有效样本量比 62 小。

### 3.8 覆盖率与区间宽度

#### 3.8.1 覆盖率是什么

**严谨说法.** 对 $N$ 个实验，每个实验有一个真实浓度 $y_i$ 和一个预测区间 $[\ell_i,u_i]$，覆盖率定义为

\[
\hat p=\frac{1}{N}\sum_{i=1}^{N}\mathbf 1\{y_i\in[\ell_i,u_i]\},
\]

其中 $\mathbf 1\{\cdot\}$ 是指示函数：真值落在区间内记 1，否则记 0。名义覆盖率是方法声称的 $1-\alpha$（例如 90%），实际覆盖率是 $\hat p$。

**通俗说法.** 做了 $N$ 次考试，每次老师给一个“答案范围”；覆盖率就是“真答案落在这个范围内的次数比例”。

**怎么读.** 覆盖率是**区间构造程序**的性质，不是某一个区间的性质。对单次实验，区间要么罩住真值，要么没罩住，没有“91.9% 的概率”这种说法；91.9% 是说“如果重复整套实验很多次，这个程序平均能罩住约 91.9%”。

**有限样本的不确定性.** 即使真实覆盖率正好是 90%，$N=62$ 时观测到的 $\hat p$ 也会上下跳。二项标准误近似为

\[
\mathrm{se}(\hat p)=\sqrt{\frac{p(1-p)}{N}}.
\]

$p=0.9,N=62$ 时约 $3.8\%$；95% 区间大约 $\pm 7.5$ 个百分点。所以“91.9%”和“90%”在 62 条数据上并不能区分；$N=12$ 时标准误约 $8.7\%$，更不能再细分。报告覆盖率时必须同时说 $N$，否则数字没有意义。

**整体覆盖 ≠ 分组覆盖.** 91.9% 可能由“大部分容易实验都罩住、少数难实验全漏”组成。本项目因此还报告按 NH₃ 档位、文件块分组的覆盖率；分组共形的总体覆盖率仍在 87.1–91.9%，但宽度没有明显收紧。**总体覆盖率会掩盖局部失效**，这是区间评估里最常见的陷阱之一。

#### 3.8.2 区间宽度是什么

**严谨说法.** 第 $i$ 个区间的绝对宽度是 $w_i=u_i-\ell_i$；相对宽度是

\[
w_i^{\mathrm{rel}}=\frac{u_i-\ell_i}{|\hat y_i|},
\]

其中 $\hat y_i$ 是该实验的预测值（或真值，需在文中说明）。本项目在 log 浓度空间构造 CV+ 区间：

\[
[\ell_i,u_i]=\hat\theta_i\pm q\cdot\widehat{\mathrm{se}}_i,
\qquad
w_i^{\mathrm{rel}}=\exp\left(q\cdot\widehat{\mathrm{se}}_i\right)-1,
\]

其中 $\hat\theta_i=\log\hat c_i$，$q$ 是折外分数的分位数。取指数是因为浓度为正、误差更适合在相对尺度上比较。

**通俗说法.** 宽度就是“答案范围有多宽”；相对宽度是“这个范围相当于预测值的百分之几”。同样宽 $\pm 2$，对浓度 10 是 $\pm20\%$，对浓度 1000 只有 $\pm0.2\%$，所以必须看相对宽度。

**怎么读.** 通常看**中位数**和 **p90**：中位数告诉你“典型区间多宽”，p90 告诉你“最宽的 10% 有多宽”。只看平均会被少数极宽区间拉偏；只看中位数会忽略尾部。本项目报告的中位宽度是：

| 窗口 | H₂ 相对宽度中位/% | NH₃ | NO₂ |
|---:|---:|---:|---:|
| 5 s | 23.09 | 13.09 | 47.26 |
| 10 s | 13.34 | 5.79 | 17.91 |
| 60 s | 8.90 | 5.80 | 14.06 |

这张表说明：窗口越长，区间越窄；NO₂ 在 5 s 最宽（47.26%），因为它的时间常数最长（约 10.6 s），5 s 时只完成约四成上升，曲线斜率小、对浓度不敏感；H₂ 虽然相对幅度只有约 1%，但时间常数约 3 s，5 s 已接近平台，所以区间反而没那么宽。宽度不是“越小越好”这么简单，必须和覆盖率一起看。

#### 3.8.3 覆盖率与宽度的权衡

对同一个估计器和同一套数据，**把分位数 $q$ 调大，覆盖率会上升，宽度也会上升**。极端情况下，区间取 $(-\infty,+\infty)$，覆盖率 100%，但完全没用。所以区间评估至少要看两维：

- **给定覆盖率目标，谁更窄**：在 90% 覆盖率附近，比较中位宽度/p90 宽度；
- **给定宽度目标，谁覆盖率更高**：例如要求相对宽度 $\le 10\%$，看多少实验能达到。

本项目的自适应停止就是第二种用法：对每个实验，找最早满足“三气体最大相对宽度 $\le$ 目标”的时间窗。结果是：

- 10% 宽度目标：只有 14/62 条能达到（中位 15 s）；
- 20% 目标：51/62 条（中位 10 s）；
- 30% 目标：60/62 条（中位 10 s）。

这说明“10 秒就能给出很窄区间”只对一部分实验成立；对难例，必须继续测到更晚，或者承认区间不够窄。这正是宽度指标的实际价值：它把“能不能停”变成一个可计算的决策，而不是拍脑袋。

#### 3.8.4 为什么本项目的覆盖率会失败

这是本项目最重要的方法学发现之一。

**（1）原始 Laplace：16.1/59.7/32.3%。** Laplace 区间围绕 MAP 估计，宽度由局部 Hessian 决定。它假设“后验在最优解附近是二次的、模型没有大偏差”。但当前正模型有约 3% 的曲线偏差，MAP 估计本身有偏；区间中心偏了，se 再准也罩不住真值。**区间失效不是噪声太大，而是模型偏差。**

**（2）剖面似然：21.0/38.7/29.0%。** 剖面似然本应比 Laplace 更可靠，但它同样以模型似然为中心。真值处的 $\Delta\mathrm{SSR}$ 已经约 197，而 95% 阈值只有 3.84；剖面被常数模型偏差主导，根本不是以 0 为中心的二次形。所以剖面覆盖率也低。

**（3）协方差 Laplace：98.4/91.9/95.2%（H₂/NH₃/NO₂）。** 把残差协方差纳入后，se 被放大 2–12 倍，覆盖率上去了，但区间变得很保守；这是“用宽度换覆盖率”，不是“模型变准了”。

**（4）CV+：91.9%（总体）。** CV+ 用折外分数校准 $q$，在总体上把覆盖率拉回名义值附近；但它是**边际覆盖**，不保证每个气体、每个档位、每个实验都覆盖。分组共形的总体覆盖率 87.1–91.9%，宽度没有明显收紧；说明“校准覆盖率”和“提高精度”是两件事。

**结论.** 覆盖率高和区间窄都只是必要条件，不是充分条件。一个可用的区间要同时满足：**覆盖率接近名义值、宽度足够小、并且在关键分组上没有系统性失效**。本项目最终只能说 CV+ 在总体上校准得还可以，不能声称每个实验的区间都可信。

#### 3.8.5 在本项目中的使用

- **第一阶段**：没有做区间估计；$3\sigma$ 是相对误差的尾部宽度，不是覆盖率。不要把它和 CI 混为一谈。
- **第二阶段**：用 Laplace 和 CV+ 给出浓度区间；报告 90%/80% 覆盖率、宽度中位数、分组覆盖率，以及自适应停止的宽度目标。
- **误差预算**：用中位数/p90 比较 real / grey 生成 / hybrid 生成三种曲线下的浓度误差；这不是覆盖率，而是误差分布。
- **决策**：自适应停止用“最大相对宽度 $\le$ 目标”作为停止规则；10% 目标只有 14/62 条可实现，说明“早停”不是无条件的。

#### 3.8.6 常见误读

- **“覆盖率高就是好区间。”** 把区间拉宽就能提高覆盖率；必须同时看宽度。
- **“区间窄就是好。”** 窄但漏掉真值，比宽而覆盖更糟；覆盖率和宽度要一起看。
- **“91.9% 表示这个实验有 91.9% 的概率落在区间里。”** 不是；这是程序在重复实验下的平均覆盖比例，单次区间没有这个概率。
- **“62 条数据的覆盖率就是总体概率。”** 有限样本有抽样误差；62 条还有采集顺序和分组结构，不能当独立同分布。
- **“分组共形一定更好。”** 它改善了分组覆盖的公平性，但本项目里宽度没有明显收紧，总体覆盖率也仍在 87.1–91.9%，不能宣称全面更优。

### 3.9 相关与因果

**严谨说法.** 相关度量两个变量之间的统计关联（Pearson 看线性，Spearman 看单调）；因果需要识别假设、干预或额外结构。相关本身不能确定方向，也不能排除混杂。

**通俗说法.** 一起变，不等于一个导致另一个。

**边界.** NH3 与 file 序号相关 0.976，但这三者（file、NH3、基线）彼此共线；不能说是“漂移导致误差”。要说因果，必须设计能分离因素的实验或给出可信的识别假设。

## 4. 曲线为什么长这样：模型

### 4.1 参数模型、灰盒与黑盒

**严谨说法.** 参数模型有固定的函数形式，参数少、可解释，但可能欠拟合；黑盒模型（如神经网络）函数形式高度灵活，主要靠数据学习，可解释性弱；灰盒介于两者之间，一部分结构来自物理/化学，一部分参数由数据拟合。

**通俗说法.** 参数模型像按图纸拼装；灰盒像先搭骨架再贴肉；黑盒像把一堆数据丢给网络，让它自己看。

**边界.** 黑盒不一定更准，尤其在小数据、强分布偏移、需要外推时；灰盒的物理骨架也可能带来系统性偏差。换黑盒不能自动修掉“设计混淆”或“没见过的档位”。

### 4.2 一阶惯性、增益、时间常数与纯延迟

**严谨说法.** 一阶惯性模型：

\[
\tau\frac{dy}{dt}=A-y,\qquad y(0)=0,
\]

加入纯延迟 $d$ 后：

\[
y(t)=A\left(1-e^{-\max(t-d,0)/\tau}\right).
\]

$A$ 是增益（最终稳定到多少），$\tau$ 是时间常数（完成 63% 变化所需时间），$d$ 是纯延迟（响应开始前的死时间）。

**通俗说法.** 像往杯子里倒水：最终水位是 $A$，杯子快满的速度由 $\tau$ 决定，水从壶嘴到杯口还有一段 $d$ 的延迟。

**边界.** 真实传感器可能有多个时间尺度、慢漂移、负响应、交叉敏感；一阶只是骨架。骨架解释不了的“剩余形状”就是残差，残差通常有结构，不是白噪声。

### 4.3 联合拟合与两阶段

**严谨说法.** 联合拟合把所有曲线放在一起，直接最小化曲线预测误差，共享参数同时优化；两阶段先对每条曲线单独估参数（如 $A, \tau, d$），再用这些估计值回归浓度。两阶段忽略了第一阶段估计误差，联合拟合则把误差传播纳入同一个目标。

**通俗说法.** 联合拟合是一边看所有曲线、一边调共同规律；两阶段是先分别量每个人的身材，再拿量出来的数字找规律。

**边界.** 联合拟合参数多、优化更难、可能陷入局部最优；两阶段更简单，但误差会从第一阶段传到第二阶段。谁更好要用折外验证，不能只看训练误差。

### 4.4 残差、低秩与 B 样条

这一节解释混合模型的后半句：**“一阶骨架 + 低秩残差”到底在算什么，B 样条又是什么。** 先给总式，再逐项拆开。

对第 $j$ 路传感器，混合模型写成

\[
y_j(t,\mathbf c)=y_j^{\mathrm{grey}}(t,\mathbf c)+r_j(t,\mathbf c),
\]

其中 $y_j^{\mathrm{grey}}$ 是一阶惯性骨架，$r_j$ 是骨架没解释的残差。残差再参数化为

\[
r_j(t,\mathbf c)
=\sum_{k=1}^{K}\phi_k(t)\,\psi_{jk}(\mathbf c),
\qquad
\psi_{jk}(\mathbf c)=X(\mathbf c)^\top\boldsymbol\beta_{jk},
\]

其中 $\phi_k(t)$ 是第 $k$ 条时间基（B 样条），$\psi_{jk}(\mathbf c)$ 是这条时间基的“音量”，由浓度的二次特征 $X(\mathbf c)$ 决定，$\boldsymbol\beta_{jk}$ 是待估系数。本项目取 $K=5$。

#### 4.4.1 残差是什么

**严谨说法.** 对第 $i$ 条实验、第 $j$ 路传感器，残差定义为

\[
r_{ij}(t)=y_{ij}(t)-\hat y_{ij}^{\mathrm{grey}}(t),
\]

其中 $y_{ij}$ 是实测相对响应，$\hat y_{ij}^{\mathrm{grey}}$ 是一阶骨架的预测。把所有实验、所有时刻的残差按“时间 × 实验”排成矩阵：

\[
\mathbf R_j=
\begin{bmatrix}
r_j(t_1,\mathbf c_1) & \cdots & r_j(t_1,\mathbf c_N)\\
\vdots & & \vdots\\
r_j(t_T,\mathbf c_1) & \cdots & r_j(t_T,\mathbf c_N)
\end{bmatrix}
\in\mathbb R^{T\times N},
\]

本项目 $T=299$、$N=62$。

**通俗说法.** 残差就是“骨架没画对的那部分”。一阶骨架已经画出了主趋势，但真实曲线还会在起始段有点偏、20 s 后缓慢漂移、不同实验之间略有差异；这些剩下的形状就是残差。

**怎么理解数学表达.** 残差不是“噪声”的同义词。它至少包含三类东西：

1. **系统性的模型偏差**：一阶指数形状不够，起始段/尾部有固定偏差；
2. **实验特异性**：不同实验的基线、增益、漂移、温度历史不同；
3. **随机噪声**：逐点测量抖动。

低秩残差只想抓住前两类中**可重复、成片出现**的部分；随机噪声不应该被基函数拟合进去。所以“残差小”不等于“噪声小”，也不等于“模型正确”。

**在本项目里.** 一阶骨架的 LOGO 宏 nRMSE 是 3.47%，混合模型降到 3.02%；逐气体从灰盒的 5.29/1.69/3.43% 降到 4.46/1.54/3.06%（H₂/NH₃/NO₂）。改善主要来自 H₂ 和 NO₂ 的尾部漂移与起始段偏差，NH₃ 本来就被一阶模型拟合得很好（约 1.5%）。

**边界.** 残差里如果混进了采集顺序、传感器老化等“伪影”，低秩基也会把它们当成规律学进去。这时残差项虽然降低了训练误差，却不代表物理上更正确。

#### 4.4.2 为什么叫“低秩”

**严谨说法.** 把残差矩阵做分解：

\[
\mathbf R_j\approx\boldsymbol\Phi\,\mathbf B_j,
\qquad
\boldsymbol\Phi\in\mathbb R^{T\times K},
\quad
\mathbf B_j\in\mathbb R^{K\times N},
\]

其中 $\boldsymbol\Phi$ 的每一列是一条时间基，$\mathbf B_j$ 的第 $k$ 行是“第 $k$ 条时间基在各实验上的系数”。因为 $K\ll \min(T,N)$，这个近似是低秩的：$\mathrm{rank}(\mathbf R_j)\le K$。本项目进一步让系数随浓度平滑变化：

\[
\mathbf B_j=\boldsymbol\beta_j\,\mathbf X_{\mathrm{all}}^\top,
\qquad
\boldsymbol\beta_j\in\mathbb R^{K\times M},
\quad
\mathbf X_{\mathrm{all}}\in\mathbb R^{N\times M},
\]

其中 $M=10$ 是浓度二次特征数。代回去：

\[
\mathbf R_j\approx\boldsymbol\Phi\,\boldsymbol\beta_j\,\mathbf X_{\mathrm{all}}^\top.
\]

对一个新的浓度 $\mathbf c$，残差预测是

\[
r_j(t,\mathbf c)=\boldsymbol\phi(t)^\top\boldsymbol\beta_j X(\mathbf c),
\]

其中 $\boldsymbol\phi(t)=[\phi_1(t),\dots,\phi_K(t)]^\top$；这里把 $X(\mathbf c)$ 视为 $M$ 维列向量。

**通俗说法.** 62 条残差曲线，不需要 62 套完全独立的形状；可以假设它们都由同样的 5 种“基本形状”按不同音量组合而成。音量不是随实验乱变，而是随浓度平滑变化。就像 5 个固定音色的乐器，每首曲子只是调整各自的音量。

**怎么理解数学表达.** 这个分解有三层：

- $\boldsymbol\Phi$：**时间字典**，5 条固定形状，负责“残差长什么样”；
- $\mathbf X(\mathbf c)$：**浓度特征**，10 个二次单项式，负责“音量怎么随浓度变”；
- $\boldsymbol\beta_j$：**耦合系数**，把时间形状和浓度特征连起来，是唯一从数据里学的部分。

参数数量是 $3\times K\times M=3\times5\times10=150$ 个（三路传感器各 50 个），比“每个时刻、每个实验都自由”少得多。这就是“低秩”的实际收益：**用共享结构换更稳的估计**。

**和 PCA/SVD 的区别.** 低秩也可以用数据驱动的 SVD/PCA 做：取残差矩阵的前 5 个奇异向量作为时间基。但本项目用的是**固定 B 样条基**，不是从数据学出来的。原因是：

- 62 条实验太少，数据驱动的基容易过拟合；
- 固定基更平滑、可复现、可解释；
- 固定基让模型对 $\boldsymbol\beta$ 是线性的，可以用一次岭回归解出，不需要非线性优化。

代价是：如果真实残差形状不在 5 条 B 样条的张成空间里，模型会欠拟合。K=6 只比 K=5 好 0.06 个百分点（2.96% vs 3.02%），说明 5 条已经够用，再增加主要是方差。

#### 4.4.3 B 样条是什么

**严谨说法.** B 样条（B-spline）是定义在节点序列（knot vector）

\[
\mathbf k=(k_0,k_1,\dots,k_{m+p+1})
\]

上的一组分段多项式基函数。给定阶数 $p$（degree，最高次幂为 $p$），第 $i$ 条基函数由 Cox–de Boor 递推定义：

\[
B_{i,0}(t)=
\begin{cases}
1,& k_i\le t<k_{i+1},\\
0,& \text{otherwise},
\end{cases}
\]

\[
B_{i,p}(t)
=\frac{t-k_i}{k_{i+p}-k_i}B_{i,p-1}(t)
+\frac{k_{i+p+1}-t}{k_{i+p+1}-k_{i+p}}B_{i+1,p-1}(t),
\]

约定分母为 0 时该项为 0。$p=2$ 时是分段二次曲线，在内部节点处一阶导数连续（$C^1$）；$p=3$ 时是三次，二阶导数连续（$C^2$）。

**通俗说法.** B 样条是一组“平滑的小山包”：每个小山包只在局部有值，其他位置为 0；把几个小山包按不同高度叠加，就能拼出任意平滑曲线。它不是“把时间分段各拟合一条直线”，而是“很多条局部曲线平滑地重叠”。

**怎么理解数学表达.** 抓住四个性质：

1. **局部支撑**：$B_{i,p}(t)$ 只在 $[k_i,k_{i+p+1}]$ 上非零。改一个系数，只影响附近一小段，不会像高次多项式那样“牵一发动全身”。
2. **平滑拼接**：相邻基函数在节点处自动满足连续性；$p=2$ 保证曲线和一阶导数连续，不会出现折角。
3. **单位分解**：对标准（未丢第一条）的钳位基，在支撑区间内 $\sum_i B_{i,p}(t)=1$，所以基函数的线性组合可以看成“局部加权平均”，数值稳定。
4. **凸包性**：曲线落在控制点构成的凸包内，不容易产生 Runge 振荡。

这四条合起来，就是 B 样条比“299 个自由系数”或“高次全局多项式”更适合做残差时间基的原因：**灵活、平滑、局部、数值稳**。

**在本项目里.** 代码 `bspline_basis(time, n_basis, degree, t_max)` 做的是：

1. 取 $K$ 条基（`n_basis=5`），实际构造 $K+1=6$ 条标准钳位基；
2. 阶数 $p=\min(2,K)=2$，即分段二次；
3. 在 $[0,t_{\max}]$ 上均匀放内部节点（均匀节点不假设某个特定物理时段更重要；如果已知“早期瞬态/中期/缓慢漂移”的时段，可以用 P3 的结构化基）；
4. 两端节点重复 $p+1=3$ 次，形成**钳位**（clamped）基：第一条在 $t=0$ 取 1，最后一条在 $t=t_{\max}$ 取 1；
5. **丢掉第一条基**，只保留后 5 条。

为什么要丢掉第一条？因为相对响应定义为

\[
y(0)=\frac{R(0)-R(0)}{R(0)}=0,
\]

一阶骨架在 $t=0$ 也是 0，所以残差必须满足 $r(0)=0$。钳位基的第一条 $B_0(0)=1$，其余 $B_k(0)=0$；丢掉 $B_0$ 后，剩下的所有基在 $t=0$ 都严格为 0，于是残差在起点自动为零，不需要额外加一个“锚定项”或截距。这是一个很小的实现技巧，但它保证了模型不会在起点凭空跳一下。

**边界.** B 样条没有物理含义：$\phi_k$ 只是数学形状，$\beta_{jk}$ 也不是增益或时间常数。它的节点位置和条数一旦固定，就只能在 $[0,t_{\max}]$ 内插值；对更晚的时间做外推，基函数会被钳在边界，预测没有意义。K 越大越灵活，但越容易吸收噪声和伪影；K 要用折外验证选，不能用全部数据选。

#### 4.4.4 为什么用“时间基 × 浓度特征”的乘积

**严谨说法.** 残差是二维函数 $r_j(t,\mathbf c)$：既随时间变，也随浓度变。直接把它展成 $(t,\mathbf c)$ 的联合多项式，参数会爆炸；更自然的假设是**可分离**：

\[
r_j(t,\mathbf c)\approx\sum_{k=1}^{K}\phi_k(t)\,\psi_{jk}(\mathbf c),
\]

即“时间形状”和“浓度音量”相乘再相加。这就是低秩/张量分解的思想：时间方向用 $K$ 个基，浓度方向用 $M$ 个特征，联合参数只有 $K\times M$，而不是 $T\times M$。

**通俗说法.** 不学“每个时刻、每个浓度组合各长什么样”，而是学“有几种时间形状”和“每种形状的音量随浓度怎么变”。这样见过的浓度组合能插值，没见过的组合也能按音量规律外推（但外推仍要谨慎）。

**怎么理解数学表达.** 如果固定浓度 $\mathbf c$，$r_j(t,\mathbf c)$ 就是 5 条 B 样条的线性组合；如果固定时间 $t$，$r_j(t,\mathbf c)$ 就是 10 个浓度特征的线性组合。两个方向都线性，联合起来对 $\boldsymbol\beta$ 线性，所以可以用最小二乘/岭回归一次解出。

**在本项目里.** 浓度特征取

\[
u_g=\log\frac{c_g}{c_{g,\mathrm{ref}}},
\qquad
X(\mathbf c)=[1,u_1,u_2,u_3,u_1^2,u_2^2,u_3^2,u_1u_2,u_1u_3,u_2u_3],
\]

共 10 项；$c_{\mathrm{ref}}=(16000,30,6)$。取 log 是因为浓度为正、相对变化更自然；二次项允许“增益随浓度弯曲”，交叉项允许“一种气体改变另一种气体的影响”。

**边界.** 可分离假设是一种建模选择，不是物理定律。如果真实残差存在“时间形状随浓度强烈改变”的交互，固定 5 条时间基可能不够；这时需要更多基、结构化基，或者让时间基也随浓度变化（更复杂的模型）。

#### 4.4.5 岭回归怎么解，为什么不用交替优化

**严谨说法.** 固定 $\boldsymbol\Phi$ 和 $X$ 后，残差模型对 $\boldsymbol\beta_j$ 是线性的。把第 $j$ 路的所有训练残差排成向量 $\mathbf r_j\in\mathbb R^{NT}$，特征矩阵 $\mathbf F_j\in\mathbb R^{NT\times KM}$，则

\[
\hat{\boldsymbol\beta}_j
=\arg\min_{\boldsymbol\beta}\,
\|\mathbf W_j^{1/2}(\mathbf F_j\boldsymbol\beta-\mathbf r_j)\|^2
+\lambda\|\boldsymbol\beta\|^2,
\]

闭式解为

\[
\hat{\boldsymbol\beta}_j
=\left(\mathbf F_j^\top\mathbf W_j\mathbf F_j+\lambda\mathbf I\right)^{-1}
\mathbf F_j^\top\mathbf W_j\mathbf r_j.
\]

代码里 $\mathbf W_j=w_j\mathbf I$，$w_j=1/\mathrm{mean}(y_j^2)$，用来让三路传感器的误差量级大致可比；$\lambda=10^{-2}$。

**通俗说法.** 时间基和浓度特征都固定后，只剩“每条基的音量”要学；这是一次带罚款的线性回归，可以直接解，不需要像神经网络那样反复迭代。

**怎么理解数学表达.** 惩罚项 $\lambda\|\beta\|^2$ 把系数往 0 拉：B 样条相邻基高度相关，浓度二次项之间也相关，不加惩罚时最小二乘解方差很大；加一点惩罚，用少量偏差换更稳的估计。$\lambda$ 越大，残差越平滑、越保守；越小，越贴近训练残差。

**在本项目里.** 训练分两步：

1. **先拟合一阶骨架**：`FirstOrderArrayModel().fit(...)`，45 个参数，非线性最小二乘；
2. **冻结骨架，算残差**，构造 $\mathbf F_j$，对每路传感器解一次岭回归，得到 50 个系数（$K\times M=5\times10$）。

这不是交替优化：骨架只拟合一次，残差只解一次线性系统。好处是简单、可复现、训练快；坏处是骨架的误差会进入残差，残差可能“替骨架背锅”。如果骨架严重错，残差会吸收过多结构，$A/\tau$ 的可解释性也会变差。

**边界.** $\lambda$ 和 $K$ 都是超参数；本项目 $K$ 用 LOGO 敏感性选（K=1..6 的宏 nRMSE 为 3.27/3.18/3.09/3.07/3.02/2.96%，取 K=5），$\lambda=10^{-2}$ 是固定值，没有逐折调。严格说，超参数选择也会带来轻度泄漏；K 的曲线很平，影响有限。

#### 4.4.6 结果、作用和边界

**结果.** 混合模型把 LOGO 宏 nRMSE 从灰盒的 3.47% 降到 3.02%，逐气体为 4.46/1.54/3.06%；直接岭回归仍是 2.59%，说明“插值最准”不等于“结构最好”。结构化 5 基（P3）进一步到 2.90%，改善主要来自 NO₂；默认模型仍用自由 B 样条，结构化模型作为可选对照。

**作用.** 低秩残差让模型在保留 $A_j,\tau_j,d_j$ 解释的同时，补上一阶骨架画不出的系统偏差；它比“再加一个黑盒”更可控，也比“直接逐时刻岭回归”更有结构。它还能把残差分解成“时间形状 × 浓度音量”，方便看哪段时间、哪种浓度组合最容易出错。

**边界.** 残差基没有物理含义，可能吸收漂移和采集伪影；它只在 $[0,60]$ s 内有效，不能外推到更晚；浓度方向用二次多项式，远离设计域时外推不可控；K 和 $\lambda$ 仍是超参数。最重要的是：**残差项降低的是曲线误差，不直接等于浓度估计误差**；后者还要看可辨识性、估计器和实验特异性。

### 4.5 岭回归

**严谨说法.** 岭回归（ridge regression）是带 L2 惩罚的最小二乘：

\[
\hat\beta=\arg\min_\beta\ \|X\beta-y\|^2+\lambda\|\beta\|^2.
\]

惩罚项把系数往 0 拉，降低方差，但会引入偏差；$\lambda$ 通常由交叉验证选择。

**通俗说法.** 拟合时给系数加一笔“别太大”的罚款，防止模型为了记住训练数据而把系数调得离谱。

**边界.** 岭回归是线性的，不会自动学到动态结构；它只能在给定的时间点/特征上取值。插值可能很准，但外推到没见过的浓度组合仍不可控。本项目里的 `direct_ridge` 是“逐时间点”版本，下面单独说明它为什么只是强插值基线。

#### 4.5.1 逐时间点岭回归为什么“没有动态结构”

本项目的 `direct_ridge` 不是“用一段历史预测下一时刻”，而是对每个采样时刻 $t_m$ 单独做一次静态回归：

\[
\hat y_j(t_m\mid \mathbf c)=X(\mathbf c)^\top\boldsymbol\beta_{j,m},
\qquad m=1,\dots,299,
\]

其中 $X(\mathbf c)$ 是 10 个对数浓度二次单项式。等价地，它训练了 299 个“浓度 → 该时刻响应”的小模型；每个时刻的系数独立，彼此不知道对方存在。代码里用一次多输出 `Ridge` 实现，只是把 299 个回归向量化，数学上仍是逐时刻独立。

**（1）为什么没有动态结构。** 动态结构的核心是“当前响应如何由过去、自身状态或时间演化决定”，例如

\[
\tau\frac{dy}{dt}=A-y,
\qquad
y_t=\phi y_{t-1}+\varepsilon_t,
\]

或者卷积/RNN。它们共享跨时间的参数，能描述上升速度、延迟、平台。逐时间点岭回归没有状态、没有导数、没有历史、没有共享时间参数；它把时间当成 299 个互不相关的任务，甚至不把 $t$ 当输入，$t$ 只是目标的位置。因此：

- 它不能保证曲线平滑、单调、从 0 开始；
- 它不能回答“如果采样率变了，曲线应该怎样”；
- 它不能把“快/慢”写成一个参数；
- 它只能在训练网格上拟合形状，不能模拟动力学。

注意：**“没有动态结构”不是因为岭回归是线性的。** 线性 AR(1)、线性 ODE 也是动态的；问题在于逐时间点独立、没有跨时间耦合。要让它动态，需要把历史响应/状态作为输入并跨时间共享参数（ARX、状态空间、TCN），而不是每个时刻各拟合一套系数。

**（2）为什么“不能回答任意时刻”。** 模型本身只在 $t_1,\dots,t_{299}$ 上有定义；对任意 $t$，它没有系数 $\boldsymbol\beta(t)$。代码里的 `predict_relative` 对非网格时间做 `np.interp`：相邻点线性插值，区间外取端点值。这是**显示层的插值/截断**，不是模型学会了任意时刻的响应：

- $t=0.1$ s 得到的是 0 和 0.2 s 两个预测的线性平均，不是指数上升；
- $t=100$ s 得到的是 59.6 s 的平台值，模型并不知道之后会不会漂移；
- 它无法在“没采样的时间”上表达一个时间常数。

灰盒/混合模型把 $t$ 写进公式 $1-\exp(-\max(t-d,0)/\tau)$，所以对任意 $t$ 都有定义（包括插值和有条件的模型外推），这是“连续时间模型”和“离散时间点查表”的区别。外推仍然可能错，但至少“外推”是模型的一部分，而不是 `np.interp` 的端点截断。

**（3）为什么“不能解释增益/时间常数”。** 它的参数是 $\boldsymbol\beta_{j,m}$：在时刻 $t_m$、某个浓度单项式每变化一点，响应平均变化多少。这里没有单一的 $A_j$、$\tau_j$、$d_j$：

- 稳态增益只是“$t=59.6$ s 的预测值”，不是模型参数；NH₃ 在 60 s 仍未完全平台，所以连这个值也不等于真正稳态；
- 时间常数只能事后拿 299 个预测点再拟合一条指数曲线得到，属于“对预测结果再做总结”，不是模型本身约束；曲线抖动或只覆盖部分上升段时，这个总结不稳定；
- 系数混合了基线、动态、交叉敏感和采集漂移，不能解释成物理灵敏度。

灰盒模型则把 $A_j(\mathbf c),\tau_j(\mathbf c),d_j$ 显式参数化，拟合时所有时间点共享这些参数；所以能直接读出“这个浓度下增益多大、时间常数多长”，也能进一步算 CRLB。

**（4）那它为什么还是“强插值基线”？** 因为每个时刻都有一个 10 维二次响应面，299 个时刻各自拟合，灵活性极高；在训练网格内，它可以把每个时间切片都拟合得很准。62 折 LOGO 2.59%，甚至低于混合模型的 3.02%。这正说明：**插值精度高 ≠ 有动态结构**。它适合做“精度上限/强基线”，用来问“灰盒为了可解释性损失了多少精度”；不适合做需要任意时刻、增益/时间常数、外推或机理分析的模型。

**常见误解.** “它能 `predict` 任意 $t$，所以有动态结构”——不，它只是插值/截断；“把 $t$ 加进特征就有动态结构”——加 $t$ 只是变成二维静态响应面，仍然没有状态和历史；“岭回归是线性的所以没有动态结构”——线性不是问题，逐时刻独立才是。

**一句话.** 逐时间点岭回归是 299 张“某时刻的静态照片”，每张都拍得很准；灰盒/混合模型是一段“有运动方程的视频”。照片能告诉你这一帧长什么样，但不能告诉你下一秒会怎么动，也不能直接告诉你“速度”和“加速度”是多少。

### 4.6 TCN

**严谨说法.** Temporal Convolutional Network，时间卷积网络。它用因果卷积（只看过去，不看未来）和膨胀卷积（跳着看更远的历史）堆叠，扩大感受野，输出可以依赖一段历史窗口。

**通俗说法.** 专门看时间序列的神经网络：用一串卷积核扫前几秒的波形，一层层扩大“能记住多长历史”。

**边界.** 小数据下容易过拟合，需要标准化、调参、早停；TCN 的插值能力不等于档位外推能力。它也不是“有了网络就不需要物理模型”；在本项目里，TCN 主要作为对照，而不是误差归因工具。

### 4.7 插值、外推与过拟合

**严谨说法.** 插值是在训练数据支撑范围内预测；外推是预测到支撑范围之外；过拟合是训练误差很低但泛化误差高，模型学到了训练集的噪声/偶然结构。

**通俗说法.** 插值是“考试题都见过”；外推是“没见过的新题型”；过拟合是“死记答案，换一道题就不会”。

**边界.** 插值好不代表外推好；外推误差无法由训练集直接验证，只能靠留一档位、物理约束或额外数据。62 条数据的边角很少，外推结论必须特别小心。

## 5. 从曲线反推浓度：逆问题与不确定度

正问题是“给定浓度，曲线长什么样”；逆问题是“给定曲线，浓度是多少”。这一节要回答四个层层递进的问题：

1. **数据够不够唯一确定浓度？** —— 可辨识性；
2. **在噪声下，理论上最好能估到多准？** —— Fisher 信息与 CRLB；
3. **实际估计有多不确定？** —— MAP、Laplace、共形区间；
4. **误差到底花在哪，为什么区间会失效？** —— 误差预算、协方差、剖面似然。

先记住一句话：**逆问题难，往往不是因为我们不会解方程，而是因为方程本身信息不够、噪声被放大、模型还有偏差。**

### 5.1 病态逆问题与可辨识性

**严谨说法.** 记正向映射为 $F:\mathbf c\mapsto \mathbf y$，逆问题就是求 $\mathbf c=F^{-1}(\mathbf y)$。Hadamard 意义下良定的问题要求：解存在、解唯一、解对数据连续依赖。三者任一不满足，就是病态（ill-posed）。可辨识性（identifiability）进一步问：在给定模型、噪声水平和观测时间窗下，不同的 $\mathbf c$ 是否会产生可区分的数据。局部可辨识性可以用正向映射对参数的雅可比矩阵 $\partial F/\partial\mathbf c$ 是否满秩来判断；全局可辨识性则要考虑整个参数域。

**通俗说法.** 三种气体可能调出几乎一样的曲线；或者曲线只差一点点噪声，反推出来的浓度就跳得很远。这时不是“算法不够聪明”，而是数据里没有足够的信息把三个浓度分开。

**怎么理解数学表达.** 设两个不同浓度 $\mathbf c_1\neq\mathbf c_2$，如果 $F(\mathbf c_1)\approx F(\mathbf c_2)$，那么观测 $\mathbf y$ 就无法区分它们。雅可比矩阵的列向量描述“某个浓度变一点，曲线往哪个方向变”；如果两列几乎平行，说明两种气体对曲线的影响几乎一样，逆问题就接近奇异。条件数越大，这种“几乎一样”越严重，噪声越容易把解推得很远。

**在本项目里.** 三路传感器对三种气体都有交叉敏感：H₂ 通道对 NO₂ 很敏感，NH₃ 通道的响应又慢又大。更关键的是，如果连初始基线 $R_0$ 也当成未知量，那么 $R_0$ 和浓度会近乎简并：把 $R_0$ 调低一点、浓度调高一点，曲线可以几乎不变。数值上，未知 $R_0$ 时 Fisher 信息矩阵的条件数达到 $10^5$–$2.9\times10^6$；而 $R_0$ 已知时，中位条件数约 20–42，最差的代表实验约 750。因此本项目**不做盲基线联合估计**：$R_0$ 作为已知/测量输入，只估计三个浓度；盲基线只作为“为什么不能这么做”的反例。

**反映什么问题.** 逆问题难，不一定是因为传感器少，而是因为“三路输出—三种气体”的映射本身接近共线，且 $R_0$ 与浓度互相抵消。换更大的网络不能创造信息；它只能改变我们利用信息的方式。

**作用.** 可辨识性分析告诉我们：哪些参数可以估、哪些必须已知、哪个时间窗信息量最大。它是后面 CRLB、MAP 和实验设计的共同前提。

### 5.2 Fisher 信息与 CRLB

**严谨说法.** 对参数 $\boldsymbol\theta$（这里取 log 浓度），单次观测的 Fisher 信息矩阵为

\[
\mathbf I(\boldsymbol\theta)
=\sum_{t}\mathbf J_t^\top\boldsymbol\Sigma^{-1}\mathbf J_t,
\qquad
\mathbf J_t=\frac{\partial \mathbf f(t;\boldsymbol\theta)}{\partial\boldsymbol\theta},
\]

其中 $\boldsymbol\Sigma$ 是噪声协方差。在模型正确、参数在内部、估计无偏且正则等条件下，任何无偏估计器的协方差都满足

\[
\mathrm{Cov}(\hat{\boldsymbol\theta})\succeq \mathbf I(\boldsymbol\theta)^{-1},
\]

右边就是 CRLB（Cramér–Rao 下界）。把 $\mathbf I^{-1}$ 的对角线开根号，再换算成相对浓度，就得到“相对 CRLB”。

**通俗说法.** 曲线对浓度越敏感、噪声越小、观测点越多，信息矩阵越大，理论误差下限越低。CRLB 是“这套数据和噪声条件下，神仙来了也只能做到这么好”的下界，不是“实际一定能做到”。

**怎么理解数学表达.** $\mathbf J_t$ 是“第 $t$ 个时刻的曲线对三个浓度的斜率”；$\boldsymbol\Sigma^{-1}$ 是“噪声越小、越独立，权重越大”。把它们按时间累加，就是总的曲率。如果某个方向曲线几乎不变（$\mathbf J$ 的列接近零），信息矩阵在该方向很小，求逆后 CRLB 很大——这正是“不可辨识”的数学表现。

**在本项目里.** 用二阶差分 MAD 估出相对噪声约 $[1.0\times10^{-5},2.91\times10^{-5},1.94\times10^{-5}]$（H₂/NH₃/NO₂；H₂ 被平滑得更厉害，取了下限）。对代表性实验计算 CRLB：

| 时间窗 | H₂ 相对 CRLB / % | NH₃ / % | NO₂ / % |
|---:|---:|---:|---:|
| 2 s | 0.083 | 0.056 | 0.116 |
| 5 s | 0.026 | 0.015 | 0.033 |
| 60 s | 0.005 | 0.001 | 0.003 |

2 s 的 CRLB 已经小于 1%，5 s 更低；而实际 10 s 的中位绝对相对误差是 4.89/2.95/7.53%。**理论下界和实际误差差了两个数量级**，说明瓶颈不是噪声，而是模型偏差、实验间差异和设计混淆。CRLB 只反映“噪声+局部曲率”，不包含这些系统误差。

**反映什么问题.** 第一，早期窗口在信息量上并不差，10 s 估计是可行的；第二，继续堆更大的黑盒不会把 7% 拉到 0.03%，因为差距不在噪声；第三，CRLB 不能拿来当“实际精度承诺”，它只是诊断工具。

**作用.** 它给“多早能估”“哪个气体最难”“时间窗值多少”提供了定量标尺，也解释了为什么本研究把重点放在偏差分解和不确定性校准，而不是继续换模型。

### 5.3 噪声、MAD 与误差预算

**严谨说法.** 观测模型是 $y_t=f_t(\mathbf c)+\epsilon_t$。噪声 $\epsilon_t$ 可能是加性的、乘性的、异方差的、时间相关的。MAD（Median Absolute Deviation）是稳健的尺度估计：对二阶差分

\[
d_t=y_{t+1}-2y_t+y_{t-1}
\]

取中位数绝对偏差，再换算成噪声标准差。若 $y_t$ 局部近似线性、噪声独立同方差，则 $\mathrm{Var}(d_t)=6\sigma^2$，MAD 到标准差的换算系数是 $1/0.6745$，所以

\[
\hat\sigma=\frac{\mathrm{MAD}(d)}{0.6745\sqrt{6}}.
\]

误差预算（error budget）则是把同一个估计器分别用在“实测曲线”“混合模型生成曲线”“灰盒生成曲线”上，比较浓度误差，判断误差主要来自哪里。

**通俗说法.** 噪声是读数抖动；MAD 是不被极端值带偏的“抖动尺子”；误差预算是记账：同样一个学生，做真题、做模拟题、做自己出的题，分数差多少，差在哪。

**怎么理解数学表达.** 二阶差分把缓慢的曲线趋势消掉，剩下的主要是噪声；取中位数而不是均值，是为了不被尖峰带偏。除以 $\sqrt 6$ 是因为二阶差分把相邻三个噪声叠加，方差变成 $6\sigma^2$。这个估计假设局部平滑；如果数据被平滑过，噪声会被低估。

**在本项目里.** 估出的相对噪声是 $[1.0\times10^{-5},2.91\times10^{-5},1.94\times10^{-5}]$。H₂ 原始数据被平滑得几乎无逐点噪声，二阶差分 MAD 接近机器精度，所以设了 $10^{-5}$ 的下限；这不是“H₂ 没有噪声”，而是“逐点噪声低于我们可估的范围”。误差预算（5 s / 60 s 中位绝对相对误差，%）：

| 曲线来源 | 5 s H₂/NH₃/NO₂ | 60 s H₂/NH₃/NO₂ | 读法 |
|---|---:|---:|---|
| 实测曲线 + 混合估计 | 9.20/5.38/20.42 | 3.24/1.64/3.94 | 真实任务 |
| 灰盒生成 + 混合估计 | 3.21/2.63/4.98 | 1.26/0.48/0.84 | 模型错配 |
| 混合生成 + 混合估计 | 0.07/0.03/0.09 | 0.00/0.00/0.00 | 自洽/神谕 |

**怎么读这张表.** 第一行是“真实考试”，第二行是“用一本较简单的教科书出题”，第三行是“自己出题自己考”。第三行接近 0，只证明反推程序没 bug，不证明模型正确；第一行减第二行的差（约 6/3/15 个百分点）才是“真实实验比模型世界多出来的困难”，包括基线漂移、实验间差异、设计混淆。

**反映什么问题.** 噪声和估计器不是主要瓶颈；模型偏差与实验特异性才是。H₂ 和 NO₂ 在 5 s 最差，因为它们的相对信号小、NO₂ 还是负响应，早期斜率不足以支撑浓度。

**作用.** 误差预算把“精度差”拆成可行动的方向：要么改模型（减少灰盒-混合差），要么处理实验特异性（基线/漂移），要么接受早期信息不足（加长窗口）。它不是严格的方差分解，不能把三项相加当成总误差。

### 5.4 MAP、先验与软墙

**严谨说法.** 贝叶斯视角下，后验

\[
p(\mathbf c\mid\mathbf y)\propto p(\mathbf y\mid\mathbf c)\,p(\mathbf c),
\]

最大后验估计（MAP）等价于最小化负对数后验：

\[
\hat{\mathbf c}
=\arg\min_{\mathbf c}\ \sum_{t}\frac{(y_t-f_t(\mathbf c))^2}{\sigma_{\mathrm{eff}}^2}
+\sum_{g}\frac{(\log c_g-\log c_{g,0})^2}{\sigma_{\mathrm{prior},g}^2}
+\text{软墙惩罚}.
\]

第一项是似然（拟合曲线），第二项是先验（别离设计中心太远），第三项是软墙。软墙的残差形式是

\[
\rho_g(\theta_g)=
\frac{\max(\log c_{\mathrm{low},g}-\theta_g,0)
+\max(\theta_g-\log c_{\mathrm{high},g},0)}{w},
\qquad w=0.15,
\]

其中 $\theta_g=\log c_g$。它不是硬边界：越界不会直接报错，而是让目标函数增长得越来越快。

**通俗说法.** 既要拟合曲线，又别猜得太离谱；先验是“根据已知设计范围，先站在中间”，软墙是“可以越界，但越远罚得越重”。

**怎么理解数学表达.** 取 log 浓度是因为浓度必须为正，且相对误差更自然；先验中心取设计域的对数几何中心 $\log c_{g,0}=\frac12(\log c_{\mathrm{low},g}+\log c_{\mathrm{high},g})$，先验标准差 1（log 单位）是一个弱先验。软墙的 $w=0.15$ 表示“越界 0.15 个 log 单位，惩罚相当于 1 个标准差”；它让估计可以落在设计域外，但不会像硬边界那样把值钉在边界上。

**在本项目里.** 早期版本用硬边界，结果 22–33% 的估计被钉在边界上，边角实验甚至出现 $10^{-15}$ 的虚假零误差——这是优化器在边界上“卡住”，不是模型真的准。改成软墙后，25–36% 的估计仍在设计域外，但都是优化器根据数据做出的选择，误差分布更诚实。10 s 的标量 MAP 中位误差是 4.89/2.95/7.53%；P4 的协方差 MAP 是 3.12/2.14/5.00%，但区间更宽。

**反映什么问题.** 硬边界会制造“假精度”；设计域外的估计不是 bug，而是模型在说“数据把我推到了没见过的区域”。先验和软墙本身也会引入偏差，尤其是设计域边界和 NH₃-时间混淆。

**作用.** MAP 给出一个可解释的点估计，并把“设计域”变成软约束；它是后续 Laplace 和共形区间的中心。注意：MAP 只是点估计，不是完整的不确定度。

### 5.5 Laplace 近似

**严谨说法.** 在 MAP 处对负对数后验做二阶泰勒展开：

\[
\mathbf H=\mathbf J^\top\mathbf W\mathbf J+\boldsymbol\Sigma_{\mathrm{prior}}^{-1},
\qquad
\mathrm{Cov}(\hat{\boldsymbol\theta})\approx\mathbf H^{-1},
\]

其中 $\mathbf J$ 是预测对 $\theta$ 的雅可比，$\mathbf W$ 是噪声协方差的逆（标量时是 $1/\sigma_{\mathrm{eff}}^2$）。得到协方差后，对角线开根号就是每个参数的标准误。若残差有过度离散，还要乘一个尺度因子：

\[
s^2=\max\left(\frac{\sum_i r_i^2}{n-3},1\right),
\]

$n-3$ 是因为三个浓度参数已经用于拟合。

**通俗说法.** 把损失函数想成一个碗：碗越陡，估计越稳；用碗的曲率当作误差棒。碗很平，说明数据说不清；碗很陡，说明估计对噪声不敏感。

**怎么理解数学表达.** $\mathbf H$ 是损失函数在最优点的曲率；$\mathbf H^{-1}$ 是“曲率越小、方差越大”。雅可比 $\mathbf J$ 把“参数变一点”翻译成“曲线变多少”；噪声权重 $\mathbf W$ 决定哪些时间点更可信。尺度因子 $s^2$ 是对“残差比噪声模型预期更大”的补偿。

**在本项目里.** Laplace 是每个实验、每个时间窗的默认 se 来源，也是 CV+ 的输入。但原始 Laplace 区间的 90% 覆盖率只有 16.1/59.7/32.3%（H₂/NH₃/NO₂）——严重欠覆盖。原因不是公式写错，而是它只反映局部曲率，不包含模型偏差；MAP 中心偏了，se 再准也罩不住真值。把残差协方差纳入后，se 被放大 2–12 倍，覆盖率升到 98.4/91.9/95.2%，但区间变得很保守；嵌套协方差更保守（100.0/95.2/96.8%）。

**反映什么问题.** “局部曲率小”不等于“总误差小”；模型偏差是 Laplace 区间的盲区。覆盖率失败是模型问题的信号，不是区间公式的 bug。

**作用.** Laplace 提供快速、逐实验的 se，是共形校准的起点；但它不能单独作为“可信区间”的证据，必须用覆盖率检验。

### 5.6 协方差与白化

**严谨说法.** 协方差 $\boldsymbol\Sigma$ 描述误差跨时间、跨通道的相关性。若 $\boldsymbol\Sigma=\mathbf L\mathbf L^\top$，白化后的目标为

\[
(\mathbf y-\mathbf f)^\top\boldsymbol\Sigma^{-1}(\mathbf y-\mathbf f)
=\|\mathbf L^{-1}(\mathbf y-\mathbf f)\|^2.
\]

这等于把“成片相关”的误差压平成近似独立的分量，再做加权最小二乘（GLS）。协方差未知时，要从残差估计，并做收缩/正则；样本量小时，协方差估计本身很不稳。

**通俗说法.** 如果误差总是成片出现，就不要把每个时间点当独立；白化是把成片误差压平再打分。

**怎么理解数学表达.** $\mathbf L^{-1}$ 是“去相关”的线性变换；变换后，原本高度相关的方向被压缩，独立方向被保留。若 $\boldsymbol\Sigma$ 估错，白化会把某些样本推得更远，点估计未必对每个 file 都改善。

**在本项目里.** 每条曲线有 $299\times3=897$ 维残差，但只有 62 条残差曲线用来估协方差；直接估 897×897 协方差不可行，所以做了收缩和嵌套检查。协方差 MAP 把 10 s 中位误差从 4.89/2.95/7.53% 改善到 3.12/2.14/5.00%，但区间更宽、更保守；嵌套版是 3.59/1.97/5.16%，说明主结果略乐观。

**反映什么问题.** 残差相关本身就是模型偏差的证据：如果模型正确、噪声独立，残差应该接近白噪声。协方差建模能改善点估计，但不能“消除”偏差；它只是把相关结构纳入权重。

**作用.** 协方差是“误差模型”的一部分，用于白化、加权和不确定性；它也是诊断工具——残差相关越强，越说明模型还有未解释的结构。

### 5.7 共形预测与 CV+

**严谨说法.** 共形预测用“非一致性分数”校准区间。对每个校准样本，取

\[
s_i=\frac{|\hat c_i-c_i|}{\mathrm{se}_i},
\]

用校准集的有限样本分位数

\[
q=\left\lceil (n+1)(1-\alpha)\right\rceil/n
\]

的分数，构造 $\hat c\pm q\,\mathrm{se}$。在可交换性下，区间有有限样本的边际覆盖保证：$P(c\in[\ell,u])\ge1-\alpha$。CV+ 用交叉验证的折外分数做校准，使每个点都不由“训练过它的模型”打分。

**通俗说法.** 看历史上每次猜错是误差棒的几倍，取一个“保险倍数”，以后都用它。CV+ 就是“用没见过的题来估这个倍数”。

**怎么理解数学表达.** $s_i$ 把绝对误差除以该点的 se，变成“误差是几倍标准误”；$q$ 是这些倍数的经验分位数。若历史误差普遍是 se 的 3 倍，$q\approx3$，区间就是 $\pm3\mathrm{se}$。可交换性（样本顺序/分布可互换）是保证覆盖率的前提；时间漂移、档位偏移会破坏它。

**在本项目里.** CV+ 的 90% 覆盖率是 91.9%，80% 是 82.3%，接近名义值；但区间宽度不小：5 s 中位相对宽度 23.09/13.09/47.26%，10 s 13.34/5.79/17.91%，60 s 8.90/5.80/14.06%。CV+ 把“原始 Laplace 严重欠覆盖”修到“总体覆盖接近名义”，但它是**边际覆盖**，不保证每个气体、每个档位、每个实验都覆盖。

**反映什么问题.** 覆盖率可以通过校准分数修好，但宽度是代价；模型偏差没有被消除，只是被更宽的区间吸收。CV+ 的保证依赖可交换性，而本项目的 62 条实验有采集顺序和 NH₃ 档位分块，不是严格可交换。

**作用.** CV+ 给出分布无关的区间校准，是本项目报告不确定度的主方法；它也让“覆盖-宽度权衡”变成可量化的表，而不是拍脑袋。

### 5.8 分组共形

**严谨说法.** 在组内分别校准 $q_g$，例如按 NH₃ 档位或采集块分组；组内样本少于 2 条时回退到全局分位数。目标是组条件覆盖，而不是只保证总体平均：

\[
P\left(c\in[\ell,u]\mid G=g\right)\ge1-\alpha.
\]

**通俗说法.** 不同浓度档位各自定“保险倍数”，不搞一刀切。

**怎么理解数学表达.** 全局 $q$ 会让容易的组过度覆盖、难的组欠覆盖；分组 $q_g$ 让每组用自己的误差分布。但每组只有 6–14 条，分位数本身很不稳，估出来的 $q_g$ 可能忽大忽小。

**在本项目里.** 分组共形的总体覆盖率在 87.1–91.9%，但中位宽度没有下降，某些组反而更宽；原因是组内样本太少，分位数噪声大，且组间差异主要来自模型偏差而不是误差尺度。它改善了“分组覆盖的公平性”，但没有创造新信息。

**反映什么问题.** 总体覆盖率会掩盖局部失效；但分组校准不是免费的——样本少时，分组会让区间更不稳。覆盖率和宽度之间没有“既好又便宜”的魔法。

**作用.** 分组共形是稳健性检查：它告诉我们哪些组在总体覆盖率下被掩盖了。它不能替代模型改进。

### 5.9 剖面似然

**严谨说法.** 对目标参数 $\theta_g$，固定它、重新优化其余参数，得到剖面目标：

\[
\Delta\mathrm{SSR}(\theta_g)
=\min_{\theta_{-g}}S(\theta_g,\theta_{-g})
-\min_{\theta}S(\theta).
\]

在正则条件下，$\Delta\mathrm{SSR}=3.84$ 对应约 95% 的 $\chi^2_1$ 区间。本项目的目标还含先验与软墙，所以严格说是“惩罚剖面”。

**通俗说法.** 想知道某个浓度能取哪些值，就把其他浓度调到最配合，再看拟合变差多少；变差太多，就排除这个值。

**怎么理解数学表达.** 剖面不是“固定其他参数”，而是“让其他参数重新最优”；这样得到的区间只反映目标参数的不确定性。$\Delta\mathrm{SSR}$ 越大，说明这个取值越不被数据支持；3.84 是 95% 的分界。

**在本项目里.** 剖面覆盖率只有 21.0/38.7/29.0%，与原始 Laplace 一样严重欠覆盖（NH₃/NO₂ 甚至更低）。以 file 21 为例，真值处的 $\Delta\mathrm{SSR}$ 已经约 197，而 95% 阈值只有 3.84；剖面被常数模型偏差主导，根本不是以 0 为中心的二次形。所以剖面图在 $\pm6$ 个 se 内近似平坦，不能给出可解释的置信域。

**反映什么问题.** 这不是“剖面算法写错了”，而是模型本身把真值推远了。即使使用更精确的似然区间，模型偏差仍会让区间失效。换句话说：**区间方法修不好模型偏差。**

**作用.** 剖面似然是“更严格的区间”对照，用来证明问题不在区间公式，而在模型；它也是后续改进（偏差感知估计、结构化残差）的动机。

## 6. 什么时候可以停：决策

估计回答“浓度是多少”，决策回答“要不要下结论、什么时候下结论”。两者不是一回事：**估计可以很准但决策代价很高；估计区间很宽，也可能已经足够判断“高于/低于阈值”。**

### 6.1 阈值、误报与漏报

**严谨说法.** 用阈值 $\tau$ 把连续浓度分成两类，决策 $d=\mathbf 1\{c>\tau\}$。以“实际高于阈值”为正类：

- 真阳性 TP：实际高、判高；
- 假阳性 FP（误报）：实际低、判高；
- 真阴性 TN：实际低、判低；
- 假阴性 FN（漏报）：实际高、判低。

由此定义误报率 $\mathrm{FP}/(\mathrm{FP}+\mathrm{TN})$、漏报率 $\mathrm{FN}/(\mathrm{FN}+\mathrm{TP})$、精确率 $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$ 等。阈值越高，FP 越少、FN 越多；阈值越低，反过来。

**通俗说法.** 报警线；误报是“没超却报警”，漏报是“超了却没报”。报警线定得越低，越不容易漏，但误报越多。

**怎么理解数学表达.** 阈值把连续值切成两类，混淆矩阵的四个格子就是全部结果。误报率和漏报率是一对跷跷板；选择阈值本质上是选择“更怕哪一种错误”。类别比例也会影响精确率：即使误报率不变，正类很少时，精确率也会很低。

**在本项目里.** 阈值取 62 条实验的逐气体中位数，让两类样本大致平衡；这只是一个**描述性设定**，不是运行报警策略。用 90% CV+ 区间做决策：只有整个区间落在阈值一侧才决定，否则继续观测。10 s 内的结果是：

| 气体 | 已决定/62 | 正确 | 误报率（已决定中） |
|---|---:|---:|---:|
| H₂ | 40 | 36 | 10.0% |
| NH₃ | 52 | 50 | 3.8% |
| NO₂ | 48 | 45 | 6.25% |

**反映什么问题.** 决策比“估得准”容易：只要区间整体在阈值一侧，就不需要把浓度估到很窄。但误报/漏报的代价不对称时，中位数阈值不是最优；H₂ 的误报率最高，说明阈值决策对它的偏差更敏感，具体原因要结合分组误差看，不能只归因于噪声。

**作用.** 阈值决策把“浓度误差”翻译成“下游后果”，是连接模型与应用的桥梁；它也说明为什么“10 s 能决策”不等于“10 s 达到 10% 精度”。

### 6.2 期望损失与停止

**严谨说法.** 给定“高于阈值”的后验概率 $p=P(c>\tau\mid\mathbf y)$，两种动作的期望损失为

\[
L(\text{判高于})=C_{\mathrm{FP}}(1-p),
\qquad
L(\text{判低于})=C_{\mathrm{FN}}\,p.
\]

选损失较小的一侧；当最小风险 $\min(L_{\text{高}},L_{\text{低}})\le\eta$（容忍度）时停止，取最早满足的窗；若全时段都不满足，记为未决。本项目用 log-normal 近似：

\[
p=\Phi\left(\frac{\hat\theta-\log\tau}{\sigma_{\log}}\right),
\qquad
\sigma_{\log}=\frac{\text{half\_log}}{z_{90}},
\]

其中 $\text{half\_log}$ 是 90% CV+ 区间的半宽（log 空间）。

**通俗说法.** 算一算“现在下结论”和“再等等”哪个更亏；够有把握就停。误报和漏报的代价不一样时，可以把漏报设得更贵，让模型更倾向于“宁可多报”。

**怎么理解数学表达.** $p$ 是“高于阈值”的概率；判高时的期望损失是“实际低”的概率乘误报代价，判低时是“实际高”的概率乘漏报代价。两边相等时就是决策边界。容忍度 $\eta$ 越小，要求越有把握，停止越晚；代价比越大，越不愿意漏报。

**在本项目里.** 代价比 $C_{\mathrm{FN}}/C_{\mathrm{FP}}$ 扫描 1/3/10，容忍度扫描 0.05/0.10/0.20。以 H₂ 为例：代价比 1、容忍度 0.05 时，43/62 决定、4 个误报、中位停止 7 s；容忍度放宽到 0.10，决定数升到 51/62，但误报升到 11 个。也就是说，**“更早停”是用更高的误报风险换来的**。

**反映什么问题.** 停止时间不是模型单独决定的，而是“证据+代价+容忍度”共同决定的。本项目的 log-normal 近似、中位数阈值、代价比和容忍度都是描述性扫描，不是从数据学出来的最优策略；62 条实验也不独立。

**作用.** 期望损失把“什么时候停”变成可计算的序贯决策问题：随着窗口变长，$p$ 更集中、风险下降；当风险低于容忍度时就停。它比固定“10 s”更合理，也比“必须达到 10% 宽度”更贴近下游需求。

## 7. 合成数据：增强

### 7.1 生成模型、VAE 与 GAN

**严谨说法.** 生成模型学习数据分布 $p(x)$ 或条件分布 $p(x\mid c)$，并能采样出新样本。VAE（变分自编码器）用潜变量和变分下界训练；GAN（生成对抗网络）用生成器与判别器对抗训练。两者都是近似，不保证覆盖真实分布的全部模式。

**通俗说法.** 让机器学会“画”像真实数据的曲线：VAE 学“压缩再还原”，GAN 让“造假者”和“鉴定者”互相较劲。

**边界.** 生成模型只能学它见过的分布；合成数据会继承正模型的偏差。生成模型不是新实验，不能用它替代真实折外验证。本项目主线的合成曲线主要来自正模型（混合模型），不是必须用 VAE/GAN。

### 7.2 合成数据、预训练与微调

**严谨说法.** 合成数据是用模型采样得到的带标签样本；预训练是先在合成/大规模数据上学表示，再在真实数据上微调。微调会改变预训练学到的映射，效果取决于分布偏移、学习率、步数和真实样本量。

**通俗说法.** 先用模拟驾校学基本功，再上真实道路微调；模拟器再像，也不等于真实路况。

**边界.** 合成数据不是“免费的新实验”；它可能强化模型偏差。预训练/微调也不是天然更好：如果合成分布与真实分布差太远，预训练反而可能有害。

### 7.3 公平预算与等曝光

**严谨说法.** 比较“加合成数据”和“不加”时，必须固定比较口径。等曝光（equal exposure）指每个优化步骤中真实/合成样本数相同，例如 8 条真实 + 8 条合成；等真实预算（equal real budget）指真实样本总曝光相同，但合成预训练会增加总更新次数。两者回答的问题不同，也都不是“等总算力”。

**通俗说法.** 比谁吃得多，要分清“每顿吃多少”和“总共吃多少”；不然会把“多吃了几顿”误当成“食谱更好”。

**在本项目里.** 10 s 宏 MAPE：仅真实 5.71%，等曝光 4.98%，等真实预算 4.50%。但等曝光臂的 H2 从 3.24% 退化到 4.20%；等真实预算臂总更新 2500，而仅真实臂 1500，不能声称“每单位计算更优”。

**边界.** 等曝光不是等真实梯度权重；等真实预算不是等算力；25 个 (seed, fold) 共享实验，p 值只作描述。结论必须带协议，不能只报一个“4.50%”。

## 8. 统计比较与可复现

### 8.1 p 值、配对检验与 bootstrap

**严谨说法.** p 值是在原假设成立、且其他模型/抽样假设正确时，统计量取到至少与观测一样极端的概率。配对检验对同一批 (seed, fold) 上的成对差值做检验，消除一部分配对间的共同波动。Bootstrap 通过有放回重采样估计统计量的抽样分布；对有分组结构的数据，应按组（如 file）重采样，而不是按点重采样。

**通俗说法.** p 小表示“纯靠运气出现这种差异”不太可能；配对是“同一道题，两种方法各做一次再比”；bootstrap 是把数据反复抽签，看结果稳不稳。

**边界.** p 小不等于效应大或重要；非独立样本的 p 值会偏乐观；多重比较不校正会产生假阳性；bootstrap 的置信区间依赖重采样单位，按错单位会低估不确定性。

### 8.2 可复现性、artifact 与 SHA

**严谨说法.** 可复现性指固定代码、数据、环境、随机种子和运行命令，使他人能重建结果。Artifact 是运行产生的模型、CSV、图件等；SHA-256 是文件内容的哈希，用来验证文件未被改动。

**通俗说法.** 把配方、火候、成品指纹都记下来，别人能照着复刻；哈希是“指纹”，证明文件还是原来那份。

**边界.** 哈希只证明文件完整，不证明结论正确；如果只校验了产物、没有从零重跑训练，这只能叫“产物一致”，不是独立复现。本项目 P6 的快照就是这种边界：命令—产物—图件一致，但六模型 LOGO 与 P5 训练沿用了冻结产物。

## 9. 把数字放回项目

这一节不是新的概念，而是把上面的概念落到本项目的几个关键数字。读的时候先问：**这个数字是哪个协议、哪个窗口、哪个指标、哪批数据？**

### 9.1 正模型：曲线拟合

62 折 LOGO 的宏 nRMSE：

| 模型 | 宏 nRMSE / % | 读法 |
|---|---:|---|
| 均值曲线 | 31.92 | 不做建模的下界 |
| 两阶段 | 5.68 | 先逐条估参数再回归 |
| 灰盒 | 3.47 | 一阶惯性 + 延迟，45 参数 |
| TCN | 3.60 | 黑盒对照 |
| 直接岭回归 | 2.59 | 插值最准，但无动态参数 |
| 混合模型 | 3.02 | 灰盒 + 5 条 B 样条残差 |

混合模型不是“最低”，但它保留了增益/时间常数，能做误差归因和外推分析。岭回归更低，说明“曲线拟合最准”不等于“结构最好”；它为什么只是强插值基线，见 4.5.1。

### 9.2 逆问题：10 s 中位绝对相对误差

| 方法 | H2 / % | NH3 / % | NO2 / % | 备注 |
|---|---:|---:|---:|---|
| 灰盒 | 6.62 | 2.93 | 8.15 | 结构对照 |
| 混合模型 | 4.89 | 2.95 | 7.53 | 结构 + 残差 |
| 直接岭回归 | 3.69 | 2.81 | 4.60 | 当前精度基线 |
| 混合 + P4 协方差 MAP | 3.12 | 2.14 | 5.00 | 点误差改善，区间变宽 |
| 混合 + 嵌套协方差 | 3.59 | 1.97 | 5.16 | 更严格的协方差检查 |

P4 的协方差 MAP 把三条路线图目标都压到线内（H2 ≤4.0、NH3 ≤2.5、NO2 ≤6.0），但 NO2 仍略高于 ridge 的 4.60%。嵌套版说明主结果略乐观，但目标仍达标。

### 9.3 区间：覆盖不等于可信

| 区间 | H2 覆盖 / % | NH3 覆盖 / % | NO2 覆盖 / % | 读法 |
|---|---:|---:|---:|---|
| 原始 Laplace（名义 90%） | 16.1 | 59.7 | 32.3 | 严重欠覆盖 |
| 偏差协方差 Laplace | 98.4 | 91.9 | 95.2 | 偏保守，se 放大 2–12 倍 |
| 嵌套协方差 Laplace | 100.0 | 95.2 | 96.8 | 更保守 |
| 分组共形总体 | 91.9 | 91.9 | 87.1 | 覆盖接近名义，但宽度不降 |
| 剖面似然（名义 90%） | 21.0 | 38.7 | 29.0 | 模型偏差把真值推远 |

“覆盖率上去了”不等于“区间可信”。协方差区间是靠变宽换覆盖；分组共形只调分位数、不收紧宽度；剖面似然反而说明模型本身有问题。

### 9.4 增强：宏平均改善，但有代价

10 s 宏 MAPE：仅真实 5.71% → 等曝光 4.98%（p=0.0017）→ 等真实预算 4.50%（p<0.0001）。但：

- 等曝光臂 H2 从 3.24% 退化到 4.20%（p=0.006）；
- 等真实预算臂总更新 2500 vs 1500，不是等算力；
- 中位 ARE 上，等曝光臂不显著（p=0.36）；
- 25 对 (seed, fold) 不独立，p 值只作描述。

所以正确说法是“改善 NH3/NO2 与宏平均，H2 在等曝光下退化”，不是“全面超过纯真实”。

### 9.5 三句话总结

1. **正模型能用简单物理骨架解释大部分曲线，但残差有结构；逆问题的主要误差是模型偏差和设计混淆，不是噪声。**
2. **点估计可以做到 3–8%，但区间不能当保证；协方差/共形能调覆盖，不能修偏差。**
3. **合成数据能改善宏平均和 NH3/NO2，但有 H2 代价和预算不对称；任何结论都要带协议和限制。**

## 10. 常见误区清单

1. **把 MAPE 当 NMAE。** MAPE 除以真实值，NMAE 除以量程；两个分母不同，不能直接比。
2. **随机拆时间点做交叉验证。** 相邻点几乎一样，测试集会被训练集“猜中”；必须整条实验留出。
3. **用测试集选 K、选模型、选阈值。** 这就是数据泄漏；锁定测试只能最后看。
4. **把 LOGO 当外推。** LOGO 只模拟“新实验”，不模拟“新浓度档位”；留一档位才是外推检查。
5. **把相关当因果。** NH3 与 file 序号相关 0.976，不能直接说“漂移是主因”；共线因素无法分离。
6. **把覆盖率当精度。** 区间拉宽就能提高覆盖率；覆盖率高不代表点估计准，也不代表区间紧。
7. **把 p 值当效应大小。** p 小只说明“不像纯运气”，不说明改善有多大、是否重要。
8. **把合成数据当新实验。** 合成数据继承正模型偏差；它不能替代真实折外验证。
9. **把“10 s 可决策”当“10% 精度”。** 决策只需要区间落在阈值一侧，不需要区间很窄；旧 10% 宽度目标仍是 14/62。
10. **把软墙当物理约束。** 软墙只是惩罚，估计仍可能越界；它不是“浓度一定在范围内”的保证。
11. **把 CRLB 当实际误差。** CRLB 是无偏、局部、模型正确的下界；模型偏差大时，实际误差可以远高于它。
12. **把 SHA 当独立复现。** 哈希只证明文件没变；没有从零重跑训练，只能叫“产物一致”。

## 11. 术语双解速查表

| 术语 | 严谨一句话 | 通俗一句话 |
|---|---|---|
| 传感器阵列 | 多个交叉敏感通道组成的测量系统 | 三块“嗅觉细胞”一起闻 |
| 正问题 | 给定浓度，预测响应曲线 | 知道配方，推算曲线 |
| 逆问题 | 给定曲线，估计浓度 | 看曲线，猜配方 |
| 相对响应 | $(R(t)-R(0))/R(0)$ | 相对自己的起点变化百分之几 |
| 档位 | 实验因素的离散水平 | 配方表里的几档 |
| 混淆 | 因素高度相关，效应无法分离 | 分不清是气体变了还是传感器老了 |
| 数据泄漏 | 测试信息进入训练/调参 | 考前偷看答案 |
| LOGO | 每次留一条完整实验 | 每条实验轮流当“新实验” |
| 留一档位 | 留出整个浓度水平 | 把一整档题全拿走 |
| 锁定测试 | 只在最终报告使用的固定测试集 | 锁抽屉的最终考卷 |
| MAPE | 平均绝对相对误差 | 平均猜错百分之几 |
| NMAE | 绝对误差 / 训练集量程 | 误差占这门课满分多少 |
| nRMSE | 曲线 RMSE / 参考幅度 RMS | 曲线整体偏了多少 |
| 宏平均 | 各气体指标等权平均 | 三门课取平均分 |
| 覆盖率 | 真值落入区间的比例 | 区间有没有罩住真值 |
| 灰盒 | 物理结构 + 数据拟合参数 | 骨架 + 贴肉 |
| 一阶惯性 | $\tau\,dy/dt=A-y$ | 倒水，慢慢接近新水位 |
| 残差 | 观测减预测 | 模型没解释的剩余形状 |
| 低秩 | 少量基函数 × 少量系数 | 只用几种积木拼 |
| 岭回归 | 带 L2 惩罚的最小二乘 | 给系数加“别太大”的罚款 |
| TCN | 因果/膨胀卷积时间网络 | 专门扫时间波形的网络 |
| 外推 | 预测到训练支撑之外 | 没见过的题型 |
| 可辨识性 | 数据能否唯一确定参数 | 曲线能不能区分配方 |
| CRLB | 无偏估计的方差下界 | 理论上的最好情况 |
| MAP | 最大后验 = 似然 + 先验 | 拟合曲线 + 别乱猜 |
| Laplace | 用二阶曲率近似不确定度 | 用碗的陡峭程度当误差棒 |
| 共形预测 | 用折外分数校准区间 | 取一个“保险倍数” |
| 分组共形 | 组内分别校准 | 每档各自定保险倍数 |
| 剖面似然 | 固定目标参数，优化其余 | 其他浓度配合到最好，再看拟合差多少 |
| 误报 / 漏报 | FP / FN | 没超却报警 / 超了却没报 |
| 期望损失 | 概率 × 代价，选较小者 | 算一算哪种错更亏 |
| 合成数据 | 模型采样的带标签样本 | 模型自己出的模拟题 |
| 等曝光 | 每步真实/合成样本数相同 | 每顿吃一样多 |
| 等真实预算 | 真实样本总曝光相同 | 真实题总量一样，但可能多做了模拟题 |
| p 值 | 原假设下出现极端结果的概率 | “纯靠运气”的可能性 |
| 可复现性 | 固定代码/数据/环境/种子 | 别人能照着复刻 |
