# 实验分支：MLP 残差与双指数骨架

> 本文件记录 `experiment/mlp-residual-double-exp` 分支上的对照实验，**不改变主线默认模型**。
> 数据仍只有 `data/0.csv`–`data/61.csv` 共 62 条；12 条锁定测试（`TEST_IDS`）不参与训练或选型，只作描述性复核。
> 所有结果均由 62 折留一实验（LOGO）产生，未补测、未重新采集。代码与产物未 commit、未 push。

## 1. 问题与结论

两个问题：

1. 当前用 5 条 B 样条时间基 × 对数浓度二次项的低秩残差修正一阶灰盒；如果换成更强大的 MLP 学习残差，能否降低曲线和下游浓度误差？
2. 当前骨架是一阶惯性 + 纯延迟；如果换成双指数（快/慢两个时间尺度），再套用同一套残差修正与下游估计，结果如何？

**结论（先看这里）**

- **MLP 残差明显更好，但不是无条件的“换模型就赢”。** 62 折曲线宏 nRMSE 从 3.020% 降到 **1.875%**，57/62 折改善；10 s 下游三气体宏中位绝对相对误差从 5.381% 降到 **3.195%**，43/62 折改善；5 s 从 12.288% 降到 **6.002%**，49/62 折改善。收益主要在 H₂ 和 NO₂；NH₃ 的曲线只从 1.536% 降到 1.434%，下游差异不显著。
- **双指数的收益稳定但较小，且集中在 NO₂。** 单独双指数把曲线宏 nRMSE 从 3.473% 降到 3.305%（44/62），主要来自 NO₂ 3.431→3.035%；再加低秩残差为 2.872%（相对当前 hybrid 40/62 改善）。10 s 下游宏 5.381→4.800%（38/62），5 s 12.288→7.672%。但 **NO₂ 下游单独双指数为 5.757%，反而优于双指数+低秩的 6.147%**；“曲线更好”不等于“下游更好”。
- **当前不建议直接把默认模型换成 MLP。** 这次是单 seed、MLP 训练在 300 次迭代处仍未收敛、下游用的还是模型自报的 in-sample 残差尺度，且没有为 MLP/双指数重做 P4 的协方差、共形区间与停止规则。要把 MLP 升为默认，至少要先补这三类验证。
- **更值得优先投入的是残差模型，而不是更复杂的骨架。** 一阶骨架加低秩残差已经能把 NH₃ 压到 1.5% 左右；MLP 的增量主要来自 H₂/NO₂ 的非线性残差结构，而双指数只补了 NO₂ 的形状。

## 2. 协议与公平性

- **62 折 LOGO**：每次留出一条实验，61 条训练；所有模型在同一折、同一训练集上拟合，预测同一条留出曲线。
- **共享对照**：`mlp` 与 `double` 两个 part 都重新拟合 `grey_box` 与 `hybrid`；逐文件核对，两个 part 的 grey/hybrid 曲线指标最大差异为 0，说明对照一致。
- **下游协议**：对每个模型、每条留出实验、5 s 与 10 s 窗，调用 P4 的 `map_estimate`（对数浓度、多起点、软墙先验）估计浓度；误差定义为 `abs(exp(theta_hat - theta_true) - 1)`。没有为候选模型重新训练逆模型，也没有用锁定测试调参。
- **模型自报噪声**：每个模型先在自己的训练残差上算逐通道 `sigma_model`，再与测量噪声合成 `sigma_eff = sqrt(noise^2 + sigma_model^2)`，作为下游似然的尺度。因此下游差异包含“模型对自己残差尺度的估计”，不是纯粹的骨架/残差结构效应；这是本实验最重要的混杂，后文限制会再说明。
- **开发/锁定拆分**：50 条开发集用于主判断，12 条锁定测试只做描述性复核。两者不是独立同分布盲测；62 折之间也共享训练文件。
- **统计**：逐文件配对差 = candidate − baseline；报告改善折数、中位差、均值差；95% CI 为逐文件差的 bootstrap 百分位区间；p 值为双侧 Wilcoxon 符号秩检验。p 值只描述折间差异，不构成独立样本推断。
- **计算**：两个 part 各跑一次 62 折，单进程；MLP part 用时 1941.0 s（约 32.4 min），双指数 part 用时 1924.2 s（约 32.1 min）。没有为每个候选做超参搜索。

## 3. 模型与超参数

### 3.1 当前方案：一阶灰盒 + 低秩残差

- 一阶惯性 + 纯延迟，每路传感器 3 个形状参数（增益、时间常数、延迟），增益与时间常数用对数浓度的二次多项式，共 45 个参数。
- 残差修正：5 条钳位 B 样条时间基 × 10 项对数浓度二次特征，每通道 50 个系数，三通道 150 个；岭回归闭式解，`ridge=1e-2`。
- 本文件简称 `hybrid`；它是主线的默认正模型。

### 3.2 MLP 残差

- 三个气体通道各自一个 `MLPRegressor`，输入 4 维：`[log(c_H2/c_ref), log(c_NH3/c_ref), log(c_NO2/c_ref), t/t_max]`；输出该通道的残差。
- 结构：两层隐藏层，每层 64 个 tanh 单元；`adam`，`alpha=1e-4`，`learning_rate_init=2e-3`，`max_iter=300`，`batch_size=200`，`early_stopping=False`，`random_state=0`。
- 每路约 4,545 个权重，合计约 13,635 个；在 61 条训练文件的全部 299 个时间点上训练，不带 file id，也不看留出文件。
- 输入标准化用训练折统计量；输出残差加回一阶灰盒。
- 训练日志反复出现 `ConvergenceWarning: Stochastic Optimizer: Maximum iterations (300) reached and the optimization hasn't converged yet.`，说明 300 次迭代不够；这是当前 MLP 结果的已知欠训练限制。

### 3.3 双指数骨架

对通道 j、气体浓度 c：

```text
y_j(t) = s_j * A_j(c) * [ f_j(c) * (1 - exp(-(t - d_j) / tau_fast_j(c)))
                        + (1 - f_j(c)) * (1 - exp(-(t - d_j) / tau_slow_j(c))) ]
```

- `A_j(c)` 为对数浓度的二次多项式；`tau_fast_j(c)`、`log(tau_slow_j(c) - tau_fast_j(c))`、`logit(f_j(c))` 为对数浓度的一次多项式；延迟 `d_j` 限制在 0–2 s。
- 每通道 23 个参数（10 个增益系数 + 4 个 `tau_fast` 系数 + 4 个 `delta` 系数 + 4 个 `mix` 系数 + 1 个延迟），三通道共 69 个；从一阶灰盒的参数初始化，再用 `least_squares` 联合拟合，`ridge=1e-3`，`max_nfev=600`。
- `double_hybrid` = 双指数骨架 + 与 `hybrid` 相同的低秩残差修正（`HybridArrayModel(grey=double)`）。

## 6. 讨论

### 6.1 为什么 MLP 主要帮 H₂/NO₂

一阶灰盒把每条曲线压成“增益 + 时间常数 + 延迟”，残差里仍有明显的浓度×时间交互；低秩残差用 5 条固定时间基 × 10 项浓度特征，能表达一部分，但表达能力受基函数形状限制。MLP 直接学 `(log c, t)` 到残差的连续映射，H₂ 的慢上升、NO₂ 的尾部形状都能被更灵活地吸收，所以 H₂/NO₂ 的曲线和下游都明显下降。

NH₃ 的残差更接近“每条实验各自的差异/不可约噪声”：曲线只降 0.10 pp，下游 10 s 的中位差 −0.65 pp 也不显著；5 s 甚至均值略升。继续加大网络容量未必有用，反而可能记住 file 特异模式。

### 6.2 为什么双指数只帮 NO₂

NO₂ 的响应有明显快/慢两个阶段，一阶模型用一个时间常数无法同时拟合早期上升和后期尾部；双指数多一个时间尺度，NO₂ 曲线从 3.431% 降到 3.035%。H₂ 的慢上升更像“增益随时间变化”或残差结构，不是第二个指数；NH₃ 的一阶形状已经够好。因此双指数是**NO₂ 的骨架消融**，不是通用替换。

### 6.3 曲线更好不等于下游更好

双指数单独的下游 NO₂ 10 s 为 5.757%，优于双指数+低秩的 6.147%，尽管后者的曲线更好（2.633% vs 3.035%）。原因是下游估计对“曲线形状在 5–10 s 窗口内的斜率/曲率”敏感，残差修正可能把训练集上的平均形状修得更准，却改变了早期窗口的局部形状；也可能与 `sigma_model` 自报尺度有关。这个反例说明：**不能用曲线 nRMSE 代替下游浓度误差做模型选择**。

### 6.4 成本与可解释性

- MLP 约 13,635 个权重，训练 62 折约 32 min；低秩残差 150 个系数，闭式解，几乎不增加正模型拟合时间。MLP 的推理成本也更高。
- 双指数 69 个参数，仍可解释为快/慢时间常数；但参数间相关、单次初始化可能落入局部最优，拟合稳定性不如一阶灰盒。
- 从论文叙事看，低秩残差+一阶骨架仍是主模型：参数少、可解释、与 P1–P6 的所有校准/停止结果一致。MLP 更适合作为“精度上界/消融”，而不是直接替换。

## 7. 限制

1. **单 seed**：MLP 只跑了 `random_state=0`，没有 seed 方差；57/62 的改善幅度可能随初始化波动。双指数没有多起点。
2. **MLP 欠训练**：训练日志明确报 300 次迭代未收敛；没有学习曲线、没有调 `max_iter`/`hidden_layer_sizes`/`alpha`。当前 1.875% 可能是下限附近，也可能因欠训练而非最优。
3. **双指数单次初始化**：从一阶灰盒初始化后只做一次 `least_squares`，没有多起点或剖面；69 个参数在 61 条实验上可能有过拟合/局部最优。
4. **下游尺度混杂**：`sigma_model` 是训练残差的 in-sample 尺度；MLP 容量大，训练残差更小，`sigma_eff` 更小，下游似然更“自信”。因此 MLP 的下游改善不能全部归因于骨架/残差结构，需用固定噪声尺度或嵌套残差重跑才能分离。
5. **没有重做 P4**：候选模型只比较点误差；没有为 MLP/双指数估计残差协方差、做嵌套验证、分组共形或停止规则。不能把本文件的点误差与 P4 的协方差区间直接混用。
6. **共享 nuisance**：`estimate_noise`、`concentration_bounds` 仍用全部 62 条估计，和 P1 一样不是严格嵌套；锁定 12 条只作描述，不构成独立盲测。
7. **62 折不独立**：同一批 62 条实验反复出现在不同折的训练集；Wilcoxon 符号秩检验的 p 值只描述折间差异，不应当作独立样本推断。
8. **未做多种子/多折划分**：折划分固定，未检查对折随机性的敏感性。

## 9. 建议的下一步

1. **先验证 MLP 的稳定性**：至少 3 个 seed；把 `max_iter` 提高并记录 `n_iter_`/损失曲线；确认 57/62 的改善不是单次初始化偶然。
2. **分离下游尺度混杂**：用固定 `sigma`（例如测量噪声或 hybrid 的 `sigma_model`）重跑 MLP 的下游，或改用嵌套残差尺度；否则“MLP 下游更好”有一部分来自更小的自报噪声。
3. **再决定是否升为默认**：若稳定，给 MLP 残差重做 P4 的协方差/嵌套协方差、分组共形与停止规则，确认区间和决策也变好；否则保留 hybrid 为默认，MLP 作为高精度可选模式。
4. **双指数只作为 NO₂ 的骨架消融**：多起点/剖面验证后，再考虑是否用于 NO₂ 专门模型；不要把 `double_hybrid` 当作通用替换。
