# GAN / PCA / VAE / PCA+VAE 数据增强对比

## 1. 实验设置

- 数据：固定 50 个开发实验 + 12 个锁定测试实验；
- 窗口：10 秒，`raw_delta` 6×51；
- 生成器只在 50 个开发实验上拟合，测试集不参与；
- 每个方案生成 3× 训练样本（40 条真实 → 120 条合成/折）；
- 下游 TCN：同一模型结构、同一五折划分、同样 3 个 seed；
- 所有方案本轮都**不加噪声、不加 aux**，只比较生成器本身；
- 测试集只在最后统一评估一次；
- 测试指标为三 seed 集成的 RMSE、NMAE、MAPE。

代码：

- `tcn_union/pca_generator.py`：条件 PCA + 高斯残差基线；
- `tcn_union/direct_vae.py`：直接对 51×3 曲线建模的条件 VAE；
- `tcn_union/gan.py`：条件 GAN；
- `tcn_union/vae.py`：PCA 响应基 + 条件 VAE（PCA+VAE）；
- `tcn_union/generative_metrics.py`：生成质量指标；
- `tcn_union/compare_generators.py`：生成质量对比；
- `tcn_union/compare_downstream.py`：下游指标汇总。

## 2. 生成曲线对比

![真实与生成曲线](artifacts/generative_comparison/fig_generated_curves_comparison.png)

- 灰色：真实开发集曲线；
- 彩色：各方案生成曲线（每格 40 条）。

直观观察：

- **GAN**：H2/NH3 出现明显折线和交叉，形态偏离真实曲线；
- **PCA**：很平滑，但曲线接近直线，缺少真实响应的弯曲细节；
- **VAE**：形态较自然，但局部有高频抖动；
- **PCA+VAE**：最接近真实形态，平滑且保留浓度趋势。

## 3. 生成质量指标

定义：

- **Wasserstein Distance**：逐气体、逐时间点的一维经验 W1 距离，按真实标准差归一化后对时间/气体取平均；越低越好；
- **ACF Distance**：lag=1..10 的自相关函数距离；越低表示时间相关结构越接近真实；
- **Pairwise Distance Ratio**：合成样本平均两两距离 / 真实样本平均两两距离；越接近 1 越好；
- **Nearest Neighbor Distance**：合成样本到最近真实样本的平均距离（按真实标准差归一化）；过低可能表示在复制训练样本，过高表示离真实分布太远。

| 方案 | Wasserstein ↓ | ACF ↓ | Pairwise Ratio →1 | NN Distance ↓ |
|---|---:|---:|---:|---:|
| GAN | 0.2299 | 0.0608 | 0.894 | 4.515 |
| PCA | 0.1302 | 0.0402 | 0.971 | 0.603 |
| VAE | 0.0793 | 0.0793 | 1.009 | 0.430 |
| **PCA+VAE** | **0.0711** | **0.0120** | **1.007** | **0.340** |

![生成质量指标](artifacts/generative_comparison/fig_generative_metrics.png)

解读：

- GAN 的 Wasserstein 和最近邻距离都明显最差，说明生成曲线整体偏离真实分布；
- PCA 的 Wasserstein/ACF 比 GAN 好，但生成形态过于线性，下游表现也差；
- VAE 的多样性最好（Pairwise Ratio 1.009），但 ACF 距离比 PCA+VAE 大，说明时间结构不够真实；
- PCA+VAE 的 Wasserstein 和 ACF 最好，NN 距离最低；但 NN 过低也提示它可能偏“贴近训练样本”，需要结合 Pairwise Ratio 和下游结果一起看。

## 4. 下游 TCN 测试结果

## 5. 结论

1. **GAN 不适合当前小样本**：生成质量最差，下游 OOF/测试都明显退化；
2. **纯 PCA 不够**：生成曲线过于平滑、接近直线，下游测试仍很差；
3. **纯 VAE 可用但不够稳**：测试比 clean 好，但 OOF 略差，生成曲线的 ACF 不如 PCA+VAE；
4. **PCA+VAE 是四种纯生成方案中最好的**：测试 macro-NMAE `0.020694`、MAPE `3.5590%`，优于 clean 和纯 VAE；
5. **但纯生成增强仍不足以超过“噪声 + PCA+VAE”的最终方案**：
   - 纯 PCA+VAE 测试 `0.020694`；
   - 噪声 0.1 测试 `0.018002`；
   - 噪声 + PCA+VAE 测试 `0.017942`；
   所以最终方案同时保留测量噪声和 PCA-VAE，而不是只用生成器。

> 重要限制：纯 PCA+VAE 的 OOF `0.029248` 并不优于 clean `0.027097`，但测试更好；12 个测试实验下不能据此宣称“生成式增强稳定优于 clean”。更稳的结论是：**生成式增强单独使用收益有限，和测量噪声组合后才在开发集三种子平均和测试集上表现更好。**

## 6. 复现

```bash
# 生成质量指标 + 曲线图 + 指标柱状图
uv run python -m tcn_union.compare_generators \
  --manifest artifacts/splits/manifest.csv \
  --output-dir artifacts/generative_comparison \
  --samples 200 --epochs 300

# 四种方案的下游训练 + 测试评估
for g in gan pca vae direct_vae; do
  uv run python -m tcn_union.gan_train \
    --manifest artifacts/splits/manifest.csv \
    --output-dir artifacts/downstream_comparison/$g \
    --modes gan --generator $g \
    --synthetic-ratio 3.0 --gan-epochs 300 --max-epochs 500
  uv run python -m tcn_union.augmentation_evaluate \
    --manifest artifacts/splits/manifest.csv \
    --baseline-dir artifacts/tcn \
    --model-dir artifacts/downstream_comparison/$g/gan \
    --output-dir artifacts/downstream_comparison/$g/evaluation \
    --windows 10
done

# 汇总图和 CSV
uv run python -m tcn_union.compare_downstream \
  --root artifacts/downstream_comparison \
  --output-dir artifacts/downstream_comparison
```

## 7. 汇报时的说法

> 我们把 GAN、PCA、VAE、PCA+VAE 放在同一训练/评估协议下比较。GAN 和纯 PCA 生成质量或下游表现明显失败；PCA+VAE 在生成质量指标和测试集上都是四种纯生成方案里最好的。但纯生成增强的 OOF 并没有稳定超过 clean，说明单独生成式增强收益有限；最终方案把 PCA-VAE 与真实测量噪声组合，才取得了更稳的 OOF 和更好的测试结果。

不要说：

- “PCA+VAE 在所有指标上都最好”——NN 距离和 OOF 并非全面最优；
- “生成式增强一定提升泛化”——只有 12 个测试实验，且 OOF 未稳定改善；
- “GAN 完全无效”——它是小样本/当前配置下失败，不应外推成 GAN 永远不行。
