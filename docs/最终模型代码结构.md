# 最终模型代码结构

这份文档只说明“最终 10 秒模型”需要读哪些文件。探索期的 40 多种增强配方已经删除，避免和最终模型混在一起。

## 阅读顺序

| 顺序 | 文件 | 作用 |
|---|---|---|
| 1 | `tcn_union/data.py` | 校验 CSV、截取 5/10 秒前缀、构造 `raw_delta` 六通道 |
| 2 | `tcn_union/model.py` | 因果 TCN：3 个残差块、膨胀率 1/2/4、输出三种浓度 |
| 3 | `tcn_union/augment.py` | 训练时 cutout：随机挖掉最多 2 秒，用两端直线桥替换 |
| 4 | `tcn_union/train.py` | 训练循环、验证/早停、EMA、checkpoint；`main()` 是旧基线入口 |
| 5 | `tcn_union/augmentation_train.py` | 最终训练入口：5 秒 clean + 10 秒 cutout+辅助+EMA，三 seed |
| 6 | `tcn_union/augmentation_evaluate.py` | 冻结后锁定测试集评估 |
| 7 | `tcn_union/plot_augmentation.py` | 测试集结果图 |

## 最终训练流程

```text
50 个开发实验
  ├─ 5 秒 clean：五折 OOF → 231 epoch → 3 个 seed
  └─ 10 秒 final：五折 OOF → 255 epoch
        cutout（最多 2 秒）
        + 5 秒辅助监督（位置 25，权重 0.5）
        + EMA 0.99
        → 3 个 seed → 集成
12 个锁定测试实验：只在方案冻结后评估
```

## 已删除的探索代码

- `AugmentConfig` 的 30 多个字段和 40 多种配方；
- 噪声、增益、偏移、时间缩放、transient、mixup、前缀保持、多前缀长度；
- 对应的通用配置解析和 `--config-5s/--config-10s` 参数。

这些算子只保留在历史文档和 git 提交里，不再进入最终模型代码。

## 行为验证

重构前后用同一数据、同一 seed、同一 epoch 对比：

- 5 秒 OOF 预测逐文件最大差值：`0.0`；
- 10 秒 OOF 预测逐文件最大差值：`0.0`；
- 最终 5 秒/10 秒 checkpoint 的 `state_dict` 最大差值：`0.0`；
- 锁定测试指标保持一致：10 秒三 seed 集成 macro-NMAE `0.016692`、macro-MAPE `3.2587%`。

## 复现

```bash
# 只跑最终方案的五折 OOF
uv run python -m tcn_union.augmentation_train \
  --manifest artifacts/splits/manifest.csv \
  --output-dir artifacts/improvement/final_ema \
  --oof-only

# 5 秒 clean + 10 秒最终模型，三个 seed 重训
uv run python -m tcn_union.augmentation_train \
  --manifest artifacts/splits/manifest.csv \
  --output-dir artifacts/improvement/final_ema

# 冻结后评估
uv run python -m tcn_union.augmentation_evaluate \
  --manifest artifacts/splits/manifest.csv \
  --baseline-dir artifacts/tcn \
  --model-dir artifacts/improvement/final_ema \
  --output-dir artifacts/improvement/evaluation_ema
```
